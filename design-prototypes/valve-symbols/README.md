# 阀门组态 SVG 概念稿

本目录是设计样稿，不会自动登记到应用素材库。

## 语义

- `CheckValveNeutral.svg`：止回阀工程图例，只表达允许流向，不假定实时状态。
- `CheckValvePassing.svg`：存在阀位反馈或可由流量可靠推断时，表达正向通过。
- `CheckValveBlocking.svg`：存在反馈或可靠工况推断时，表达反向截止；截止是正常保护，不使用报警红色。
- `TwoWayValveNeutral.svg`：两通阀工程图例，蝴蝶结阀体加执行机构。
- `TwoWayValveOpen.svg`：水平阀位标记加贯通流道，表达打开。
- `TwoWayValveClosed.svg`：垂直阀位标记加阀喉阻断线，表达关闭。
- `ValveSymbolConcepts.svg`：六种图例的深色组态画布对照表。

## 推荐状态映射

| 状态 | 轮廓 | 几何冗余 | 颜色建议 | 文本 |
| --- | --- | --- | --- | --- |
| 未知/无反馈 | 固定阀体 | 无动态叠加 | 中性灰 | `UNKNOWN` |
| 打开/正向通过 | 固定阀体 | 水平阀位、贯通线或正向箭头 | 正常态绿或项目可配置色 | `OPEN` / `PASSING` |
| 关闭/反向截止 | 固定阀体 | 垂直阻断线、阀瓣贴座 | 中性灰 | `CLOSED` / `BLOCKED` |
| 开启中/关闭中 | 固定阀体 | 阀位轮廓或轻量运动提示 | 状态色描边 | `OPENING` / `CLOSING` |
| 故障/反馈矛盾 | 固定阀体 | 独立告警标记 | 红色 | `FAULT` |

单向阀通常是被动元件，不应在没有位置或流量反馈时模拟成可点击的 On/Off 开关。两通阀若支持调节，建议在图元旁显示 `0–100%` 开度；`0%` 和 `100%` 分别映射关闭、全开，中间值仍使用打开轮廓并显示具体百分比。

## 参考

- ISA-5.1 / ISA-5.5：工程图与过程显示使用一致的仪表、控制和阀体图形语言。
- ISA-101：组态 HMI 的图形、颜色和动态元素应形成一致的站点规范。
- Siemens LBP / MTP 图例：区分打开、关闭、开关过程中、未知和故障等反馈状态。
- Belimo / Siemens 两通阀资料：两通阀具有明确端口、流向、常开/常闭及位置反馈语义。
