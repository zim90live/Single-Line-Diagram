# AIDC 一次接线图编辑器

面向 AIDC 运维人员的桌面端 Web 编辑器。当前版本完成第一阶段基础编辑与图元锚点定义闭环：冷却/电力双线路、园区/楼宇/POD/设备层级下钻、图元编辑、资产级接线锚点、本地项目保存以及 JSON 导入导出。

## 启动

环境要求：Node.js 22+。

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址。当前按 Chrome/Edge 桌面端设计，窗口宽度建议不低于 1180px。

## 当前能力

- 图元拖入或双击插入，单选、多选和框选。
- 移动、等比缩放、90° 步进旋转和 8px 网格吸附。
- 顶部/左侧标尺、画布平移和缩放。
- 页面采用顶部栏、左侧导航/素材栏、中间画布、右侧属性栏四区结构；返回、编辑/播放、缩放和状态信息以透明贴边 HUD 收入画布，不再占用独立工具栏高度。
- 属性面板编辑名称、设备标识、坐标、尺寸和角度；Generator、Grid、MP、Transformer 可修改单一实例颜色，Switch、2WV、CV 可分别配置关/开状态颜色。母线与子线支持同类多选或混合选择后批量改色；空选时按图元、母线、子线汇总当前画布颜色，三个 On/Off 图元按设备和关/开状态独立列出，可按同类同色对象全局替换。
- 顶部可切换编辑/监控模式。编辑模式选中 Switch、2WV 或 CV 后可在属性面板切换 On/Off，监控模式也可直接点击切换；三者默认 Off，状态进入项目存档与 JSON 导入导出，并由兼容运行态存储即时镜像。状态切换仍不触发项目 dirty 或撤销历史。电力移动虚线只覆盖有效 Grid→算力/动力 POD 最短业务路径，无 Target 整链和死端支路不动画，Off Switch 两侧相邻线路均停流；2WV 开启后按普通阀门双向连通，CV 开启后只允许入口→出口，二者关闭时均切断内部水路。
- 单个图元实例可配置最多 5 项数值或文本运行指标并独立显隐。编辑模式以中间数值或正常文本状态稳定预览；监控模式进入后立即生成并每 30 秒刷新，文本状态按正常优先的告警等级权重抽样。告警只改变指标值颜色，不额外显示等级文字。
- 图元设备标识默认显示并支持实例级显隐；系统自动在四侧避让锚点出线区域，单选图元后可拖动标签改变侧向。母线和独立子线可配置可选端点标签，均支持实例级显隐和受约束拖动。
- 撤销/重做、复制/剪切/粘贴、删除、全选快捷键；对象剪贴板可跨同专业图纸保留图元、母线和选区内部接线，方向键以 8px 步进流畅移动已选图元与母线。
- 冷却、电力两棵独立图纸树及层级下钻/返回。
- IndexedDB 本地保存/打开，版本化 JSON 导入/导出。
- 从素材 hover 编辑入口打开双栏锚点编辑器，在图元边缘 8px 网格点定义名称、类型和自动外向方向；冷却素材可配置为水泵、普通阀门或止回阀，水泵与止回阀使用唯一入口/出口。
- 图元锚点普通接线、网络级共享路径、自动派生分叉、正交避障与非连接拱桥；电力图纸支持可编辑母线及自动滑移 tap。

当前注册 `src/assets/symbols/` 中的 22 个 SVG 文件，呈现为 21 个逻辑图元：`SwitchOn.svg` 与 `SwitchOff.svg` 统一为稳定 `Switch`；Cabinet A 沿用原 `cabinet` 稳定键，Cabinet B 使用独立 `cabinet-b`。编辑模式已覆盖图元、锚点、普通接线和电力母线；监控首轮已覆盖电力 Switch 门控、流向动画和实例级模拟指标，冷却业务方向、真实遥测与图表后续实施。

## 操作提示

| 操作 | 方式 |
| --- | --- |
| 插入图元 | 从左侧拖入画布，或双击素材 |
| 编辑锚点 | hover 素材后点击右上角编辑图标 |
| 修改图元颜色 | 选中支持改色的单个图元，在右侧颜色字段中选择；Switch 的关/开颜色分别配置，均可恢复默认 |
| 切换 Switch 状态 | 编辑模式单选 Switch 后使用右侧“Switch 开关状态”；监控模式直接点击 Switch |
| 批量修改线路颜色 | 使用 `Shift` / `Ctrl` / `⌘` 追加选择子线或母线，再通过右侧统一颜色字段修改 |
| 配置子线标签 | 单选独立子线，在右侧填写标签；拖动标签可切换源/目标端点及横线的上/下或竖线的左/右侧，文字沿子线内侧对齐且不越过端点 |
| 全局替换颜色 | 点击画布空白，在右侧按图元、母线或子线点击一种当前颜色 |
| 调整设备标识方位 | 先单选图元，再拖动其标签到上、右、下或左侧 |
| 追加选择 | `Shift` / `Ctrl` / `⌘` + 单击 |
| 框选 | 在画布空白处拖动 |
| 平移画布 | 触控板双指移动；或按住鼠标中键拖动；或按住空格并用鼠标左键拖动 |
| 缩放画布 | 触控板捏合；鼠标滚轮；或使用工具栏 +/- |
| 复制 / 剪切 / 粘贴 | `Ctrl` / `⌘` + `C` / `X` / `V`；切换到同专业图纸后可直接粘贴，跨图纸落在当前视口中心 |
| 撤销 / 重做 | `Ctrl` / `⌘` + `Z`；`Ctrl` / `⌘` + `Shift` + `Z` |
| 全选 / 删除 | `Ctrl` / `⌘` + `A`；`Delete` / `Backspace` |

## 质量检查

```bash
npm test
npm run typecheck
npm run build
npm run test:e2e
npm run test:performance
```

`test:e2e` 使用无截图的真实浏览器 DOM 断言；测试服务使用端口 `41735`。`test:performance` 使用 `scene-archives/WuHu AIDC 0814.json` 对比完整路由与局部移动后的增量路由，只在显式执行时运行。项目约定不由自动化代理主动进行视觉验收，目视检查清单见 [第一阶段验收清单](docs/FIRST_PHASE_ACCEPTANCE.md)。
