# 母线设计简报

最后更新：2026-08-17
状态：已实现，待用户视觉与操作验收

## 1. 功能摘要

母线是电力图纸中的直线拓扑骨干，用于承载多条普通接线。它只保持水平或垂直，不产生折点，也不具有两个可接线端点。母线的视觉起止位置仅用于表达几何范围和长度，不代表电气端子。

左侧工作区以可拖入工具的方式提供母线，但母线不属于 SVG 图元素材，也不进入图元资产、锚点编辑器或普通图元变换模型。

## 2. 数据与拓扑模型

- 项目文档的 `busbars[]` 为每条母线保存稳定 ID、所属图纸、方向、网格起点和长度；可选 `label` 保存非空文字，可选 `labelEndpoint` 保存 `start | end` 几何端点方位。
- 母线首版仅允许出现在电力图纸，类型固定为电力。
- 普通线路网络新增 `busbar-tap` 节点，保存 `busbarId + offset`；持久化 offset 是沿母线方向、以世界单位表示的原始接入位置，实际绘制位置默认由路由器沿母线自动优化。
- 同一母线上的全部 `busbar-tap` 节点隐式连通。该连通关系属于拓扑语义，不生成普通线路边，也不在母线上绘制额外线路。
- 不同母线不直接隐式合并，但可以通过一条两端均为 `busbar-tap` 的显式普通电力子线互联；普通接线只在图元锚点与母线 tap 之间建立端点关系，不接入已有普通线路。
- 母线几何范围内的任意 8px 网格点都可作为接入点，包括视觉上的两端；两端不具有特殊端点语义。

## 3. 创建与编辑交互

- 图元素材下方新增“线路工具”，提供母线条目；支持拖入画布或双击插入视口中心。
- 新建母线默认水平、长度 160px，位置与长度贴合 8px 网格。
- 点击母线执行母线选择；拖动母线时沿二维 8px 网格移动，所有已有接入点随母线整体移动，普通线路自动重新路由。
- 选中母线显示几何编辑控件：两端长度手柄和旋转手柄。长度只能沿当前轴以 8px 步进调整；旋转以 90° 切换水平/垂直。
- 缩短母线可以越过已有接入点。不同 `busbar-tap` 按原有顺序随长度成比例压缩到互不重叠的 8px 网格点，最短长度为 `max((tap 数 - 1) × 8px, 8px)`；同一 tap 接多条边只计一个连接点。扩长已提交母线时不主动拉开压缩后的 tap。
- 母线支持删除、方向键移动、撤销和重做。首轮不进入普通图元的多选、复制粘贴和框选集合。
- 新建母线和旧项目母线默认没有 `label`，画布不显示占位文字。单选一条纯母线时，属性面板提供“母线标签”输入及“显示母线标签”开关；填写后在开关开启时显示，清空后删除 `label` 并立即隐藏。开关关闭只隐藏当前母线文字，保留内容与端点方位。
- 非空标签只能位于母线两个几何端点的线段外侧，默认使用 `end`。单选母线后可拖动标签，在 `start | end` 之间切换；文字始终保持水平，不随母线旋转。这里的端点仅是标签布局锚点，不是可接线端子。

## 4. 接线与交叉交互

- 接线进行中 hover 母线时，在距离鼠标最近的合法 8px 位置显示接入候选点；点击后完成接入。
- 完成接入后，tap 默认可沿所属母线滑移。路由器优先选择总路径最短、包含图元锚点出线方向在内转折最少的合法位置；同分时优先靠近用户原始点击位置并使用稳定 offset 破同分。
- 接入位置按母线法向两侧分别占用：相反两侧的接线允许共享同一个派生 8px offset，同侧接线继续避让；普通线路真正穿过母线的位置仍不可作为 tap。
- 普通状态点击母线先选择母线；选中后 hover 显示空心候选 tap，点击可从母线发起普通电力子线。接线状态下另一条母线可作为终点，同一母线不允许自连。
- 普通线路不再提供分叉候选点；母线仍只显示自身可发起或接收普通电力子线的候选 tap。
- 普通接线穿过母线但用户未明确点击母线时不连通，由普通接线绘制拱桥跨越母线。
- 已连接的普通接线在母线接入点以实心节点表达；拱桥交叉点禁止作为母线接入点。
- 普通接线不得与母线共线重叠；自动路由把母线占用的网格边作为共线障碍，但允许正交跨越。

## 5. 删除与一致性

- 删除母线时删除所有直接接入该母线的普通线路边和 `busbar-tap` 节点，再按既有规则清理孤立节点和空网络。
- 删除、移动、缩放和旋转母线均作为包含关联线路变化的单一历史事务，可一次撤销或重做。
- 导入时验证母线唯一性、所属图纸、专业类型、8px 网格、方向、最小长度、tap 引用和 offset 范围。
- 母线能力在 Schema v5 引入，当前项目格式为 v9；v1–v4 项目自动迁移为空 `busbars[]`，v7 新增可选六位 HEX `color`，v9 新增可选 `label` 与 `labelEndpoint`。

## 6. 绘制层级与视觉原则

- 延续中性深色、极简工业工作台；母线使用比普通电力接线更明确的粗实线，但不使用发光或装饰效果。
- 已建立的母线 tap 使用固定 2.5px 屏幕半径、所属母线颜色的实心点，不使用深色描边；候选接入点也继承所属母线颜色。连接点只需略大于母线描边以表达真实接入，不与可交互候选点争夺视觉层级。
- 母线文字标签复用设备标识的 10px 世界字号和画布色描边，使用独立的 8px 端点视觉间距并随画布缩放；标签不进入母线几何、框选、吸附、接线障碍或 tap 求解，也不受 8px 主网格约束。
- 绘制顺序为：网格、母线、普通线路及拱桥、图元、母线接入点、选择与变换控件、临时接线预览。
- 可见描边与透明命中描边分离，点击和拖动命中范围按屏幕尺寸补偿。
- 视觉检查和验收继续由用户完成；自动化验证聚焦模型、拓扑、几何、DOM 状态、类型和构建。

## 7. 验收标准

- 用户能从左侧拖入或双击创建母线；母线始终水平或垂直，位置和长度保持 8px 网格对齐。
- 母线可选择、移动、调整长度、90° 旋转、删除并撤销/重做；缩短可越过旧 tap 位置，全部 tap 保持顺序、8px 间距和拓扑身份并随母线一起压缩。
- 普通电力接线可接入母线任意合法网格点，同一母线上的所有支路属于同一连通网络。
- 两条不同母线可通过显式普通电力子线连接；同一母线不能自连。冷却图纸不能创建母线，冷却接线不能接入母线。
- 未连接的普通接线正交穿过母线时显示拱桥；显式接入显示实心节点，共线重叠被拒绝。
- 保存、打开和 JSON 导入导出不会丢失母线及其接入关系，v1–v4 项目可正常迁移。
- 母线文字为空时不渲染；填写且开关开启后只出现在起点或终点外侧，关闭只隐藏当前母线且不清空文字，拖动只能切换这两个方位，旋转后文字仍保持水平。标签内容、显隐和端点方位可撤销并随复制、保存和 JSON 往返保留。
- 图元锚点在母线投影范围内且没有障碍时，tap 自动滑移到对应投影网格点，使普通接线以垂直或水平最短路径接入母线。
- 母线相反两侧的图元或子线投影到同一网格点时可共点接入，且不会因另一侧已有 tap 被迫水平或垂直错位。

## 8. 实施与非视觉验证结果

- 母线在 Schema v5 新增独立 `busbars[]` 和线路网络 `busbar-tap` 节点；当前 Schema v13 继续保留，并沿用 v7 增加的可选六位 HEX `color`、v9 增加的可选端点标签及 v11 增加的可选 `labelVisible`；v1–v4 项目自动迁移为空母线集合，v8 项目无损迁移且既有母线默认无标签，v1–v10 母线缺省为标签可见。
- 同一母线 tap 已进入隐式邻接和网络合并逻辑，普通线路路由把母线网格边作为共线占用，并为未连接正交交叉生成由普通线路承担的拱桥。
- 左侧“线路工具”已支持母线拖入和双击创建；冷却图纸禁用。画布已实现母线选择、拖动、两端长度调整、90°方向切换、方向键移动、删除和撤销/重做。
- 接线状态下母线显示最近合法 8px 接入候选点；明确接入后显示实心 tap，拱桥点不可接入。删除母线会清理直接支路、孤立节点和空网络。
- tap完成接入后默认遍历母线合法8px位置，并按完整路径长度、转折数、相对原始位置的滑移距离和稳定offset自动求优；派生位置与继承颜色不改写 Schema v13 文档。
- 自动求优已将既有接入区分为同侧占用和异侧可复用；真正的非连接穿越点继续作为两侧共同禁区。
- 水平与垂直母线均已覆盖异侧共点测试；现有同侧多子线避让测试继续保留。
- 母线 tap 已从 3.5px 屏幕半径收敛为 2.5px，并移除深色描边；母线候选点和透明命中区域保持不变。
- 不同母线已支持通过显式普通子线互联；两端 tap 联合求优，网络可按既有连接合并，并在删除唯一子线后自动拆分。
- 母线缩短已按不同 tap 数量计算动态下限，并把持久化 offset 的有序压缩与母线几何作为单一历史事务；无 tap 或 1 个 tap 时可缩至 8px，5 个 tap 时最短为 32px。
- 73 项单元/组件测试通过，覆盖 v4迁移、母线校验、动态长度下限、tap 有序压缩与碰撞消解、隐式连通、网络合并/拆分、双端tap联合滑移、多子线避让、锚点方向感知、共线避让、交叉拱桥和删除清理。
- TypeScript 类型检查、主题一致性检查、机械 UI 规则检查和生产构建通过；3 条无截图 Playwright 流程通过，其中母线流程覆盖创建、图元接入、子线互联、8px 动态下限、tap 同事务撤销/重做、90°旋转和删除清理。
- 构建仍保留既有 Three.js 大分块提示和 `THREE.Clock` 弃用警告，本次未引入新的失败项。
- 当前全量 97 项单元/组件测试、主题与类型检查、生产构建及 3 条无截图浏览器流程通过。
- 端点标签增量完成后，全量 129 项单元/组件测试、类型检查、主题一致性检查和生产构建通过；新增覆盖无内容不渲染、水平/垂直双端布局、指针端点判定、v8 迁移及属性输入清空。

## 9. 用户验收重点

- 在冷却和电力图纸间切换，检查“线路工具”中母线的禁用与可用状态是否明确。
- 拖入母线并检查粗细、颜色、选中反馈、拖动手感、两端长度手柄和旋转手柄是否符合工程绘图习惯。
- 从电力图元锚点和已有普通线路分别接入母线，检查候选点、实心 tap 和自动路由是否自然。
- 在母线相反两侧放置投影坐标相同的接线，检查两侧线路能共用同一接入点；再从同侧重复接入，检查仍会避开重叠线路。
- 选择一条母线并 hover，检查空心起线点；连接到另一条平行或异向母线，检查两端 tap 联合滑移、进出方向和子线选择/删除是否自然。
- 分别用 1 个和多个 tap 缩短母线，确认长度手柄可越过旧接入位置，tap 依次压缩且不重叠；再检查撤销/重做、移动和旋转后所有支路是否稳定跟随并重新路由。
- 让普通接线正交穿过但不接入母线，检查拱桥是否明确表达不连通；尝试共线方向，检查线路是否绕开母线。
- 删除母线后检查直接支路是否同步清理，并通过撤销恢复完整母线与接线拓扑。
