# 制冷视觉流量模拟设计

最后更新：2026-09-02
状态：已实现，待用户视觉与真实图纸操作验收

## 1. 目标

在没有真实遥测和水力参数的阶段，为制冷图纸提供稳定、可解释的演示数据：用户可在监控模式选择水泵或阀门，通过右侧属性面板控制运行状态；水泵还可设置 `0–100%` 输出功率。开放管网还可在编辑模式把冷却子线的一个物理端点配置为“水流源头”。系统据此生成闭合或开放管网中的视觉流量、方向和动画速度。

本功能用于验证交互、连通关系和动画效果，不替代工程水力计算。

## 2. 运行态与交互

- 监控模式允许单选可控设备，但仍禁止移动、旋转、缩放、接线、删除和修改图纸结构。
- 选中水泵后，右侧运行面板提供“运行状态”和“输出功率”；输出功率范围为 `0–100%`、默认 `100%`。
- 选中普通阀门、2WV 或 CV 后，右侧运行面板提供“阀门状态”。2WV/CV 继续复用已有可保存 On/Off 状态；其他阀门保持会话状态。
- 水泵运行状态和输出功率属于当前会话模拟态，不进入项目 JSON、dirty 或编辑历史；2WV/CV 的既有状态快照规则不变。
- 点击设备只负责选择，不再直接切换状态，避免选中动作同时改变系统运行工况。
- 编辑模式选中一条或多条冷却子线后，右侧属性面板提供“水流源头”的“不作为源头 / 起点端 / 终点端”；混合批量值显示“多种源头”。源头端点属于持久化图纸配置，并与子线允许方向独立；方向阻断时显示冲突提示。

## 3. 首版视觉流量模型

- 每台泵使用固定基准流量 `100 m³/h`；泵的目标流量为：`运行 ? 基准流量 × 输出功率 / 100 : 0`。
- 只有出口能够经当前开启的阀门、CV 正向通路和允许方向的管线返回同一水泵入口时，水泵才向网络注入目标流量。
- 每个有效管路源头使用固定基准流量 `100 m³/h`，流向同一有效管网中其他可达、连接度为 1 的普通自由节点开放端；源头自身、图元锚点和母线 tap 不作为回收端。没有可达开放端时，该源头不注入流量。
- 管线和设备内部通路使用统一的无量纲阻力；同一逻辑边被节点分段时，其总阻力保持不变，避免手动增加节点改变分流结果。
- 并联支路按等阻力网络分配视觉流量；汇流处按流量守恒合并，多台水泵、多个管路源头及两类驱动的贡献在线性网络中叠加。
- CV 和单向子线禁止逆向流量。关闭阀门、没有有效驱动、泵闭环断开或源头没有可达开放端时不产生流量。
- 每个物理区间的有符号模拟流量决定动画方向，绝对值决定动画速度；零流量区间把对应角色显示色直接压黑 50%，并保持主要 `10px / 2px`、辅助 `4px / 1px` 的管体/内芯层级不变。

该模型只保证视觉上的连续、守恒和确定性，不读取或推断真实管径、局部阻力、泵曲线或系统压差。

## 4. 画布数据表达

- 水泵运行面板显示当前模拟流量，单位固定为 `m³/h`。
- 若水泵图元已配置名称包含“流量”或 `flow` 的数值指标，监控画布用该泵的模拟流量覆盖原随机读数；其他指标继续使用既有模拟机制。
- 动画继续沿制冷内芯复用深色移动虚线，不新增流光。移动虚线与零流量最终暗色使用和对应角色内芯相同的世界空间宽度（主要 `2px`、辅助 `1px`），由 Shader 随 zoom 换算屏幕宽度；零流量色在渲染前把角色显示色与黑色各混合 50% 并不透明绘制，避免圆角采样段重复透明叠色。输出功率和分支流量只改变速度，流量为零时只降低内芯明度，不改变角色粗细、拓扑或持久化颜色。
- 动画继续遵守后台暂停和 `prefers-reduced-motion`。

## 5. 明确不做

- 不生成或显示模拟压力，也不从流量反推压力。
- 不模拟扬程、沿程/局部阻力、管径、阀门开度、泵效率、温度耦合、自动平衡、气蚀或瞬态。
- 不把视觉流量作为告警、容量校核、设备选型或工程计算依据。
- 首版不增加额定流量配置、源头输出功率、场景编排或历史曲线；固定基准流量后续可由真实遥测或设备参数替换。

## 6. 验收

1. 监控模式点击水泵后只选中设备，右侧可启停并设置输出功率，图元不能被移动。
2. `100%` 输出时显示 `100 m³/h`；`50%` 显示 `50 m³/h` 且动画更慢；`0%` 或停泵时该泵不驱动动画。
3. 在最低、100% 和最高缩放下，制冷移动虚线及零流量深色覆盖分别与主要 `2px`、辅助 `1px` 世界空间内芯保持相同粗细；电力线路仍维持固定屏幕宽度。
4. 两条拓扑等价的并联支路得到相同流量和速度；汇流后恢复合计流量。
5. 关闭阀门、CV 反向或子线反向时，相应通路停止；开启且方向正确时恢复。
6. 多泵网络按净流量决定每个物理区间的唯一动画方向，不再因“不同闭环见证方向相反”留下无动画缺口。
7. 增删纯路径节点不改变同一逻辑边的总阻力和分流结果。
8. 所有模拟运行态变化不产生项目 dirty 或编辑历史；2WV/CV 继续遵循既有保存语义。
9. 在无水泵的开放管网把一条入口管路标记为源头后，源头区间显示 `100 m³/h`；两个等价可达出口各分得 `50 m³/h`，方向阻断或没有可达开放端时全部静止。
10. 多个显式源头与水泵闭环贡献可叠加；节点分割、反转、合并、复制和保存往返后源头仍绑定正确物理端点。
