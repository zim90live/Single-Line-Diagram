# 历史归档

## 归档规则

- 文件名使用 `YYYY-MM-DD-主题.md`；阶段性汇总也可使用 `YYYY-MM-主题.md`。
- 归档必须说明日期、来源、当时结论以及后来为何归档。
- 归档内容原则上不再原地修改；如需纠错，补充勘误说明并保留原上下文。
- 当前有效的目标与决策仍保留在上级活动文档中，不因归档而失去约束力。
