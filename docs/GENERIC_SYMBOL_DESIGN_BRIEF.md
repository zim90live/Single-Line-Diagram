# 通用图元设计说明

- 状态：已实现，待用户视觉与操作验收
- 日期：2026-08-25
- 适用范围：素材库 `generic` 图元、画布渲染、属性面板与运行指标标签

## 目标

为不能预先提供专用 SVG 的设备提供一种中性、可复用的占位图元。它既要像普通设备一样参与选择、移动、旋转、锚点接线、复制、保存和运行指标展示，又要允许用户按现场排布独立调整宽高。

## 视觉与文字

- 素材库显示“通用图元”，稳定素材键为 `generic`，默认尺寸为 `96 × 48`。
- 画布本体由近黑色背景和默认 `#777777` 的虚线矩形边框组成；右侧属性面板可修改或恢复虚线框颜色，颜色也参与画布颜色总览与全局同色替换。单选时另提供默认开启的“显示虚线框”实例开关；关闭只隐藏描边，背景、标识、锚点、运行指标和已配置颜色均保留。
- 框内白色文字显示当前 `properties.tag` 设备标识；字段为空时沿用图元名称。
- 设备标识始终显示在框内，不复用普通图元的框外名称标签，也不提供“显示图元标签”开关。运行数据仍复用现有四侧组合标签，以及“显示运行数据”“显示指标名称与单位”两个实例开关。
- 图元以 90° 步进旋转时，虚线框和锚点随图元旋转，设备标识保持画布水平方向。文字先按旋转后的水平可用宽度省略，再由旋转后的内框裁剪，双重保证不越过虚线框。

## 几何与交互

- 默认按素材声明尺寸插入，位置、宽度和高度均吸附 8px 网格。
- 单选时右侧属性面板分别显示“宽度”和“高度”，不显示普通图元的“缩放”百分比。宽度最小 32px，高度最小 24px；两者可独立改变，不限制长宽比例。
- 单选右下角缩放手柄把指针位移投影到图元本地坐标，分别调整宽高，因此旋转后的拖拽方向仍与图元本体一致。
- 多选整体缩放继续使用统一比例：普通 SVG 保持原始宽高比，通用图元保持进入手势前的自定义宽高比；所有结果落在 8px 网格。
- 继续沿用普通图元的资产级锚点定义。锚点按通用图元当前宽高分别映射，因此非等比尺寸下仍贴合对应边缘。
- 通用分类不隐含固定线路类型。在锚点编辑器中新建锚点时，默认类型取当前图纸系统：冷却图为“通用”（`cooling-general`），电力图为“电路”（`electrical`）。已经保存的锚点类型不被自动改写，仍可在编辑器中明确选择，以免改变同一资产在其他图纸中的既有接线语义。

## 数据与兼容

- 不增加 `DiagramElement` 顶层字段，也不升级 Schema。自由尺寸继续使用既有 `width`、`height`，边框色继续使用 `properties.color`，设备标识继续使用 `properties.tag`；虚线显隐保存在既有实例属性容器的 `properties.genericBorderVisible` 中，缺省或 `true` 表示显示，布尔值 `false` 表示隐藏。
- 专用渲染只由稳定素材键和已安装素材元数据决定，不把 SVG DOM、截断结果或文字坐标写入项目。
- 旧项目加载时沿用既有“同步已安装素材”流程自动获得通用图元；已有设备、锚点、线路和实例属性不变。

## 验收要点

- 素材库中能找到并插入“通用图元”，默认外观为灰色虚线框、近黑底、白色设备标识。
- 右侧分别修改宽度和高度后，另一维不被联动，结果保持 8px 网格；画布缩放手柄也能改变长宽比例。
- 修改、预览和恢复虚线框颜色正确；关闭“显示虚线框”后只隐藏描边，仍可选择、移动、旋转和接线，重新开启后恢复原颜色。保存、刷新、复制、撤销/重做后尺寸、颜色和虚线显隐不丢失。
- 分别旋转 90°、180°、270°，设备标识始终水平；短标识完整显示，长标识出现省略号且任何文字像素不越过虚线框。
- 配置数值或文本运行指标后，名称、单位、读数、文本状态和告警仍按普通图元规则显示在四周；框内设备标识不与四侧名称重复。
- 在冷却图和电力图分别新建锚点，默认类型应与当前系统兼容；自由改宽高及旋转后，锚点仍可正常起线、落线。若是修复前已创建的锚点，应在锚点编辑器中把类型改为当前图纸所需类型。
