# 自动拐角候选节点设计简报

最后更新：2026-08-24
状态：已实现，待用户视觉与操作验收

## 1. 功能摘要

编辑模式下，任何普通子线自动路由产生的正交拐角都可作为一个派生的候选节点。候选节点默认不写入项目，也不把自动路径转成手动约束；用户从该拐角拖动、从该拐角起线，或把兼容接线落到该拐角后，系统才在成功事务中把它固化为统一节点。

该能力面向需要快速搭建复杂电力或冷却管路的 AIDC 运维编辑人员。目标是在操作体验上做到“任何子线拐角都能直接当节点使用”，同时保留设备移动后的自动重路由能力。

## 2. 主要用户动作

- hover 自动拐角：显示与现有节点一致的固定屏幕尺寸空心圆。
- 双击自动拐角：直接从该位置开始接线；候选点在接线成功前仍不持久化。
- 拖动自动拐角：把该拐角固化为路径节点并进入既有节点拖动流程。
- 把兼容接线落到自动拐角：在接线成功事务中固化节点，并把新线路接入该节点。
- 单击但不拖动：沿用子线选择，不因纯选择操作修改项目或产生撤销历史。
- `Esc`、非法落点或路由无解：取消接线或拖动，不留下节点、拆边、脏数据或历史记录。

## 3. 设计方向

保持现有中性、克制、精密的画布交互，不增加工具栏、模式开关、常驻拐点标记或新属性面板。候选节点与真实节点使用同一空心圆反馈，用户只需理解“这里可以接线或拖动”，无需识别内部持久化状态。

候选节点只在编辑 hover 或接线候选状态出现；普通编辑画面与监控模式继续只显示线路。颜色沿用所属线路的兼容语义，不引入新的视觉色。

## 4. 几何与拓扑边界

- 候选点来自正式正交路由中方向发生 90° 变化的顶点，不包括线路端点、重复点、零长度区间、拱桥圆弧采样点或仅用于绘制底衬的显示几何。
- 同坐标已有真实自由节点、图元锚点或母线 tap 时，只显示并操作真实对象，不再叠加候选点。
- 普通交叉仍不连通；两条不同网络仅在画面上交叉时，不因坐标相同生成共享候选节点。
- 同一网络中多条逻辑线路实际共同经过同一拐角及其相邻物理区间时，固化应复用一个共享节点；仅视觉重合但不具备相同连通语义的路径不合并。
- 自动路由变化后，未固化候选点随派生路径移动或消失，不需要稳定 ID，也不参与复制、保存、撤销或监控拓扑。

## 5. 从候选拐角起线

双击候选点后立即复用现有节点起线会话，线路类型继承候选点所属网络。接线预览阶段只记录“网络、参与逻辑边、拐角坐标和相邻物理区间”的会话引用，不提前修改项目。

连接到兼容图元锚点、母线、现有节点或子线并通过闭环、类型和路由校验后，在同一个可撤销事务中：

1. 在原拐角创建或复用统一节点。
2. 把实际经过该拐角的参与逻辑线路插入该节点引用。
3. 创建新逻辑线路并以该节点为起点。
4. 执行同点合并、自环/退化区间清理和正式重路由。

任一步失败则整次回滚并只显示一条既有 Toast。取消接线不留下一个连接度为 2 的节点。

## 6. 关键状态

- **默认**：无常驻圆点，候选点不进入项目数据。
- **拐角 hover**：显示空心圆和“**双击从节点接线**”；该文案继续统一称“节点”。
- **拐角起线中**：显示既有正交接线预览和兼容目标反馈，原线路尚未被拆分。
- **拖动中**：使用轻量预览表达新路径；成功松手后才创建路径节点并写入一次历史。
- **提交成功**：候选点成为现有 `ConnectionNode.kind = "node"`，后续选择、移动、删除、合并和起线规则与其他节点完全一致。
- **取消或失败**：候选点消失，项目、dirty 和撤销栈不变。
- **监控模式**：不显示、不交互，也不参与 Source、Target、门控或流动计算。

## 7. 数据、性能与兼容性

- 候选态本身不新增 Schema 字段或版本；只有固化成功后才复用现有统一节点。Schema v26 起，固化节点会直接成为相邻节点边的端点，不再把它作为跨节点旧边的长期 `routeNodeIds` 保存。
- 候选点按当前可见正式路由派生，并按网络、坐标和相邻区间去重；不为整张大图预先创建 React 状态对象或领域节点。
- hover 命中优先复用当前子线空间索引和视口裁剪，避免给每个拐角常驻挂载独立命中元素。
- 保存、刷新、JSON、IndexedDB、复制和历史只处理已经固化的真实节点。
- 旧项目和既有自动线路无需迁移；首次交互时使用当前正式路由生成候选点。

## 8. 验收标准

- 任意可见普通子线的 90° 自动拐角在编辑 hover 时显示节点圆点，直线中段、端点和拱桥弧线不误显示。
- 可从候选拐角双击起线并完成到兼容锚点、母线、节点或子线的连接；完成后原拐角成为三连或更高连接度节点。
- 起线后按 `Esc`、点击非法目标或正式路由失败时不留下节点或半条线路，dirty 和撤销历史不变化。
- 候选拐角可直接拖动并固化为路径节点；纯单击仍只选择子线。
- 自动重路由导致拐角移动或消失时，未固化候选点同步更新，不形成冲突。
- 共享拐角只固化一个节点；普通交叉、不同网络重合和拱桥不错误连通。
- 固化后节点的移动、删除、同点合并、复制、保存、单向通行和监控动画继续遵守统一节点规则。
- 大型图纸不因候选拐角数量增加而显著增加常驻 DOM、项目文档大小或主线程路由耗时。

## 9. 实现参考与边界

实现时重点参考现有画布渐进披露、节点手势和接线事务；交互细节参考 Impeccable 的 `interaction-design.md`，性能与大图行为继续遵守现有视口裁剪和空间索引基线。

本增量不增加候选节点名称、属性面板、常驻显示开关、自动保存全部折点、自由曲线、任意角度线路或新的冷却 Source/Target 规则。

## 10. 开放问题

暂无。若实现中发现同一坐标存在多个互不连通但同类型的自动拐角，必须按网络与实际相邻区间保持独立候选身份，不根据坐标猜测连通。

## 11. 实现结果

- 编辑态仅在指针靠近当前正式子线的内部 90° 拐角时派生一个候选节点；直线点、线路端点、已有真实端点与互不连通的重合路径不误复用。
- 纯单击继续选择逻辑子线且不固化节点；直接拖动在首次有效位移后才建立预览，松手成功时单事务固化并进入既有节点选择、碰撞合并与冲突校验流程。
- 双击候选点使用延迟源节点进入既有接线会话；连接到兼容锚点或子线时，源拐角物化与新逻辑边在同一提交中完成。`Esc` 和未完成接线不会写入节点或线路。
- 同一网络且具有相同实际转向的共享拐角会收集全部参与逻辑边并复用一个节点；候选状态不新增 Schema 字段、不进入复制、保存、监控拓扑或常驻 DOM。
- 229 项单元/组件测试通过、1 项跳过，17 条无截图端到端流程、主题一致性、类型检查和生产构建通过。按项目约定未主动进行截图视觉验收。
