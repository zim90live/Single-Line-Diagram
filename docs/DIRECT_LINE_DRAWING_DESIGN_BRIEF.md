# 持续式线路绘制工具设计简报

最后更新：2026-09-01
状态：已确认并实现，待用户验收

## 1. 目标

用户可以先显式开启“绘制线路”工具，再从画布任意 8px 网格点、图元锚点、母线 tap、已有节点或已有子线起笔，不需要预先创建或选择始/终节点。新线是真实业务拓扑，不是装饰图形。

## 2. 交互流程

1. 点击画布 HUD 中的折线图标进入持续绘制模式；普通选择模式下点击空白处不起线。
2. 第一次单击空白网格点只建立待绘起点；单击已有锚点、母线、节点或子线时，从该拓扑位置起笔。
3. 绘制中单击空白网格点，系统新增一个自由节点和一段正交线路，并从新节点继续预览。
4. 绘制中单击已有锚点、母线、节点或子线，建立拓扑连接并结束当前连续线；工具仍保持开启，等待下一次起笔。
5. 闭环与上述“落到已有节点”一致：闭合当前线后回到等待起笔态，不退出工具。
6. `Esc` 保留已生成的有效线段并退出工具；若只落了一个尚未连线的起点，则不写入孤立节点。再次点击已选中的工具按钮与 `Esc` 一致。

## 3. 拓扑与类型

- 空白起点在电力图中创建电力线，在冷却图中创建冷却通用线；接入专用冷却网络后沿用现有类型解析规则。
- 空白端点在数据层保存为连接度为 1 的 `ConnectionNode.kind = "node"`；用户无需操作隐式的始/终节点。
- 显式点击同网络的其他节点可新增闭环边；同节点自连、两节点间的重复边和退化自环仍被拒绝。
- 线路只是几何穿越其他网络时不连通，继续使用拱桥；只有指针单击吸附到目标时才建立拓扑。
- 开路支线可正常保存、选择、编辑和删除，但在没有形成有效 Source→Target 或水泵闭合回路时不产生监控流动动画。

## 4. 历史、保存与兼容

- 一次工具开启期间生成的多段线和多条连续线合并为一个撤销步骤。
- 线段在点击后即进入当前项目文档和 dirty 状态；`Esc` 是结束绘制会话，不回滚已确认的线段。
- Schema v27 起允许连接度为 1 的自由端点和显式同网络闭环；当前 Schema v28 继续保留该语义。v1–v26 项目继续使用原迁移规则，不会平白生成新的开路端点或闭环。

## 5. 验收重点

- 未点击工具时，空白画布单击仍只执行选择/框选逻辑。
- 工具开启后可连续单击绘制折线，无双击完成逻辑。
- 落到已有拓扑目标或完成闭环后，当前线结束但工具继续开启。
- `Esc` 退出后不再从空白画布起线，已画线路保留，一次撤销移除本次工具会话的全部线路变更。
- 保存/刷新、JSON 往返、自由端点编辑、显式闭环、被动交叉拱桥和监控无流动语义保持稳定。
