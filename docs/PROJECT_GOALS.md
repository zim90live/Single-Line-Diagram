# 项目目标

最后更新：2026-09-03

## 愿景

创建一个面向 AIDC 场景的一次接线图绘制/监控系统，为电气一次系统的图形化建模、展示和运行监控提供统一工作界面。

## 当前已确认目标

1. 建设编辑、监控双模式的 AIDC 一次接线图系统。
2. 系统覆盖冷却、电力两套线路。
3. 每套线路支持多层级图纸，已明确的层级示例包括园区图、楼宇图、POD 图和设备图。
4. 支持一次接线图相关对象的运行监控，监控模式需要包含状态动画、趋势/指标图表和数据模拟能力。
5. 让项目目标、关键决策、任务状态和历史记录持续与实现同步，减少返工。

## 目标用户与交付形态

- 主要用户：AIDC 运维人员。
- 交付形态：Web 系统；第一阶段按桌面端编辑场景规划。

## 当前阶段

第一阶段基础编辑与图元锚点编辑器已于 2026-08-14 通过用户视觉与操作验收。线路连接已改为同锚点多条逻辑边与网络内可自然重合的派生路径，固定子线分叉入口和可见分叉点已移除；电力母线、tap 自动滑移、锚点方向感知路由、不同母线普通子线互联和母线缩短时的 tap 受约束压缩均已完成实现和非视觉验证。图元与母线现可混合框选、移动、旋转，并统一支持复制、粘贴和 Duplicate；选区内两端对象均被复制的逻辑接线关系会同步生成新 tap、节点、边和网络，连向选区外对象的支路不复制。框选或追加多选显式包含线路节点时，Copy/Paste 与 Duplicate 还会带上该节点直接接触的子线段；未选图元或母线一侧转换为同位置自由端点，不递归复制外部对象或下一段支路。母线和逻辑子线现可在属性面板使用应用内 HEX 颜色控件改色；子线支持跨网络追加多选，并可与一条或多条母线组成线路混合选择，统一批量预览、提交或恢复颜色。网络主干选择会批量作用于网络内全部子线，多色选择明确显示“多种颜色”；母线 tap 与候选连接点继承所属母线颜色。空选属性面板按图元、母线、子线汇总当前画布实际颜色与使用数量，可一次替换同类同色对象；Switch 关/开颜色作为独立槽位汇总和替换。每个图元设备标识默认显示，单选图元后可在右侧属性面板独立隐藏或恢复；母线与独立逻辑子线均可填写可选文字标签，空值始终隐藏，非空标签也可通过当前对象的独立开关隐藏或恢复。子线标签绑定源或目标端点，并根据端点附近派生线段的方向放在横线的上/下侧或竖线的左/右侧。独立逻辑子线还可配置双向、起点→终点或终点→起点通行；单向子线在配置终点显示固定屏幕尺寸箭头，电力拓扑不允许逆箭头传播。三类标签均保持水平世界空间文字，并支持各自既定的方位交互。图元拖动、母线拉伸、方向键连续移动与起线跟随的高频路径已改为逐帧合并和轻量几何预览；正式路由由可取消的 latest-wins Web Worker 生成派生快照，并按直接连接关系和空间影响走廊只重算脏网络。单次任务复用障碍网格，交叉与标签避让使用空间索引，拱桥显示路径按路由身份缓存；大图静态 SVG 使用视口 overscan 裁剪，接线锚点按需挂载，同色图元共享滤镜。正式普通子线不再因同网络已有主干获得复用加分；等长少折线路把拐点居中作为唯一造型偏好。非连接交叉已使用带局部底衬的真圆弧拱桥。当前等待用户继续检查设备标识显隐与标签、母线与子线端点标签、子线单向箭头、混合选择、拖动/拉伸/方向键移动/终点悬停流畅度、自然重合路径、中点拐点、类型颜色、避障/拱桥以及母线相关效果。监控模式首轮已实现顶部模式 Tab、只读画布、Switch 独立自动保存，以 Grid、Generator、Battery 为 Source、算力 POD、动力 POD、FM 为 Target 的有效最短业务路径动画，以及 Off Switch 两侧相邻线路停流和 WebGL 深色移动虚线；闭合但没有 Target 的整条电力链路及有效主干旁的死端支路均不动画。每个图元实例的运行指标现同时支持数值读数和文本状态，编辑模式稳定预览，监控模式每 30 秒刷新且文本模拟正常状态占绝大多数；右侧属性面板可用一个实例级总开关统一隐藏或恢复全部指标名称与单位，指标值、文本状态和告警颜色继续显示。工作区已收敛为顶部栏、左侧导航/素材栏、中间画布和右侧属性栏四个一级区域；左侧栏可通过右边缘纯图形入口收起并把宽度让给画布，收起状态仅当前应用会话生效。原次级上下文工具栏、画布外标题栏和状态栏已并入无背景贴边画布 HUD。画布缩放和平移现为不写项目、不持久化且不触发“未保存”的纯会话视图状态。顶部/左侧标尺与状态栏鼠标坐标已经移除，画布使用完整中间区域并继续保留自适应点阵和当前网格间隔。中键、空格+左键与触控板双指平移共用命令式共享视口：逐帧只更新 SVG 合成层和 WebGL Uniform，达到 120px 屏幕位移或手势结束时再同步 React 裁剪状态；POD A 在 25% 缩放下的基准帧时间 P95 已由约 50ms 降至 16.8ms。制冷阶段 B 已实现水泵/阀门资产角色、阀门/CV 门控和沿双层管体最终显示几何的 WebGL 移动虚线；2026-08-26 已进一步增加监控态泵阀选择与右侧运行面板、水泵 `0–100%` 输出功率、固定 `100 m³/h` 基准流量和等阻力视觉流量求解。真实遥测接入、图表、物理水力求解和监控动画规模边界仍待后续。

- 锚点定义随项目 JSON 与 IndexedDB 持久化，SVG/PNG 源文件不写入锚点元数据。

## 当前增量：线路连接与管理

### 已确认目标

- 配置了锚点的图元在 hover 时显示可用接线锚点；点击锚点开始接线，临时线路随鼠标正交增长，点击兼容图元锚点或母线完成。同一图元锚点允许重复发起或接收多条线路。
- 线路类型包括电力、一次回路冷/热、二次回路冷/热和通用；通用冷却网络在接入专用类型后整体解析为该类型，失去最后一个专用端点后恢复通用。
- 四类专用制冷线路的默认预设色固定为：一次回路冷 `#FFC800`、一次回路热 `#FF6011`、二次回路冷 `#0084FF`、二次回路热 `#00F074`；预设统一用于未自定义线路、接线锚点和锚点编辑器，显式实例颜色继续优先。
- 制冷管路统一使用双层世界空间样式与相同材质：主要线路下层为 `10px`、`#262626` 并带 `x 0 / y 1 / 模糊 3 / #FFFFFF 50%` 内阴影，上层为 `2px` 一次/二次回路冷/热色或实例色；辅助线路下层收为 `4px`、上层保留 `1px`，并把显示色调整为 `20%` 原色与 `80% #70736F` 中性灰混合。两类均使用平头管体、圆头内芯与圆角连接；粗细只表达用户显式配置的视觉层级，不改变拓扑、流量或真实管径语义，也不从连接度自动推断。
- 除图元缩放导致的非网格锚点过渡段外，线路只沿 8px 网格水平或垂直行走；系统自动选择避开图元区域的实际最短路径，并以较少转折作为次级目标。实际长度和转折数相同时，以拐点到两端中点的累计距离作为唯一造型评分；同网络已有路径不参与评分。
- 长度和转折数相同的正交路径优先让拐点靠近起点与终点的中部，避免折点无必要地贴近任一端。
- 不同线路网络允许正交交叉但默认不连通。普通子线穿越电力母线时始终由子线绘制拱桥；冷却主要线路与辅助线路交叉时始终由主要线路绘制拱桥；其余同级子线交叉继续由后创建线路跨越。实际 SVG/监控绘制同样按“母线→子线”和“辅助→主要”分层，不能让后绘制网络盖回桥面遮罩。不同网络共线重叠禁止。
- 非连接交叉的拱桥采用紧凑的真圆弧和加粗的局部画布色底衬；电力线路默认占用 8px 路径跨度并抬高 4px，底衬为 12px 屏幕线宽。制冷管路在编辑和监控模式均使用放大一倍的 `16 × 8px` 圆弧，主要/辅助线路分别使用 `18px / 12px` 世界空间画布色遮罩。拱桥只属于派生显示几何，不改变线路拓扑或项目 JSON。
- 编辑模式制冷管路的普通 90° 拐角使用 `8px` 世界空间真圆弧；相邻段不足时，半径最多取各相邻段长度的一半。同一网络在该点只有两个实际物理方向时仍视为普通弯头，包括二连节点和多条逻辑边共享的弯头；实际物理方向达到 3 个及以上时视为分叉并保持直角。紧邻拱桥的弯点不圆角。圆角只改变上层、下层、选择、命中和接线预览共用的派生显示几何，不改变 8px 路由点、节点、拓扑或保存数据。
- 当前已实现版本允许从图元锚点、母线、自由节点或显式绘线工具的空白网格点起线；兼容锚点、母线、另一网络节点和子线都可作为终点。接线落到子线时在 8px 落点创建或复用节点，同时保持原逻辑线路的颜色、标签、显隐和单向属性；用户显式连接同网络不同节点时可建立闭环，同点自连和重复边仍被拒绝。同一锚点的多条线路仍可形成不保存、不可交互的派生共同段。
- 点击独立支路选择对应逻辑连接；点击多条连接共用的主干选择整个线路网络。删除逻辑连接或网络后按剩余端点关系重新路由。
- 选中独立逻辑子线后可修改该边颜色并在重新选择后回显保存值；`Shift` / `Ctrl` / `Command` 单击可跨网络追加或移除逻辑子线，网络主干会先展开为网络内逻辑边参与选择。子线可与母线共同保留在一个线路混合选择中，通过同一颜色字段批量修改。选择内存在不同颜色时显示“多种颜色”，连续颜色输入只预览，确认后单次提交。
- 单选一条独立逻辑子线后可在右侧属性面板填写或清空可选标签，并通过实例开关隐藏或恢复非空标签。标签缺省位于目标端点的负侧；单选后可拖动到源/目标端点，并在端点附近横线的上/下侧或竖线的左/右侧切换。文字沿端点线段向子线内侧展开：横向使用左/右对齐与水平 padding，纵向使用顶/底对齐与垂直 padding，不越过子线端点。标签位置随派生路由方向更新，不保存折点坐标。
- 单选或纯子线多选后可配置双向、起点→终点或终点→起点通行；多选方向不一致时显示“多种方向”，一次修改批量作用于全部所选逻辑边并形成一个撤销步骤。母线与子线混合选择不显示方向字段。双向不显示箭头；单向在逻辑目的端显示固定屏幕尺寸箭头，电流或未来水流拓扑只能顺箭头穿过。方向配置属于逻辑边实例并随历史、复制、JSON 与本地保存持久化。
- 纯冷却子线单选、多选或网络选择后可批量设置主要/辅助级别；混合值显示“多种级别”。辅助线路以 `20%` 原回路/实例色与 `80% #70736F` 混合后的低对比色、`4px / 1px` 管体/内芯显示，原始颜色字段不变；电力子线与母线混选不显示该字段。编辑模式选中的冷却子线使用独立 `6px #B7B8B5` 高亮轨道，确保不同回路色、不同粗细和共享主干上均可辨认。
- 自动路由仍是默认行为；用户可平行拖动任意普通子线段创建或更新 8px 节点硬约束。自由节点可单独选择、移动、删除、双击起线，也可与图元和母线一起移动或旋转；路径与交汇角色按实际物理连接度派生，不保存两种对象类型。
- 共享主干的参与边使用相同节点；移动共享节点影响全部邻接边。删除二连节点恢复局部自动路由，删除三连及以上节点移除相关节点间边。选中节点间子线段后仍可从右侧属性面板“恢复自动布线”，收缩同一拆分组中可安全移除的二连路径节点，但不穿过真实分叉。
- 图元或母线变换若使未随选区移动的节点约束无解，则取消整个变换并只显示一条汇总 Toast；节点与对象共同选中时随选区移动或 90° 旋转。含节点的混合选择首版不支持整体缩放。
- 变换预检只阻止本次由有效变为无解的手动节点约束；图纸中已经无解的线路不阻止无关图元移动。任何几何变化都应重新尝试既有无解网络，使移开遮挡物后线路能够恢复，而不是永久复用旧无解状态。
- 线路支持选择、删除、撤销/重做；图元变换后自动重新路由，删除图元时清理关联支路和孤立拓扑。
- 正式网络路由在 Web Worker 中异步计算并采用 latest-wins 调度；交互和提交期间显示稳定快照的轻量预览，新建边先显示接线预览路径，最终结果到达后再无阻塞替换。

### 本轮边界

- 线路业务数据采用连通网络、图元锚点/母线 tap/自由节点和相邻节点边；不保存自动折点、派生分叉或 SVG 路径命令。
- 统一节点、手动改线、兼容子线接入与节点起线已实现：自动路由仍生成未约束区间和全部派生折点，用户只持久化少量自由节点硬约束。当前不支持任意中段/自由位置线路标签、含节点选区整体缩放或服务端协作；独立子线的受约束端点标签及选区内部拓扑复制已支持。

### 已实现：统一节点与节点起线

- 用户界面和数据模型把现有途径点、分流节点统一为一种“节点”；路径节点与交汇节点不是固定类型，而是按实际邻接物理子线段的连接度派生。
- 连接度为 1 的自由节点承担开路端点，连接度为 2 时承担路径约束，连接度大于等于 3 时承担分流/汇流；只有连接度为 0 的自由节点自动清理，图元锚点和母线 tap 等宿主端点不受影响。
- 节点单击选择、拖动移动、双击起线；编辑 hover 显示空心圆与“双击从节点接线”，普通编辑画面和监控模式不增加常驻标记。
- 从节点起线可连接兼容图元锚点、母线、现有节点或子线；新逻辑线路默认双向并使用类型默认色。显式连接同网络不同节点可建立闭环，自连和相同两节点间的重复边被拒绝。
- 删除连接度为 2 的节点会局部恢复自动路由；删除连接度大于等于 3 的节点会移除全部邻接物理线段且不恢复主管。
- 节点可与图元和母线共同移动或 90° 旋转；同点兼容节点自动合并，自由节点与已连接图元锚点精确重合时由锚点吸收节点并清理退化物理区间。拖动与图元锚点相邻的子线段时，手动节点落在锚点规定出线方向上的前一格引出点，避免路由器为满足锚点方向生成短回折线头；子线段拖回原路径或锚点过渡位置时，系统会清除本次手动段节点，并在每轮重路由后继续回收导致线路立即反向的独占路径节点，直至恢复无折返的自动路径。共享节点和分支节点不参与该回收。冲突整次回滚并只提示一次，含节点选区继续不支持整体缩放。
- 颜色、标签、显隐和单向通行继续属于逻辑线路；节点只表达坐标、拓扑与物理分段。详细方案见 `UNIFIED_CONNECTION_NODE_DESIGN_BRIEF.md`。

### 已实现：自动拐角候选节点

- 自动路由生成的普通子线 90° 拐角在编辑 hover 时表现为可操作的候选节点，但默认不保存、不进入历史，也不把自动路径转成手动约束。
- 用户可直接拖动候选拐角，或双击候选拐角派生新子线；只有拖动或接线成功后，候选点才在同一事务中固化为统一节点。取消、非法目标或无解不留下节点。
- 未固化候选点随自动重路由移动或消失；普通交叉、不同网络视觉重合和拱桥显示几何不产生连接。详细方案见 `DERIVED_CORNER_NODE_DESIGN_BRIEF.md`。
- 实现不新增 Schema 字段；纯点击、`Esc` 与未完成接线不产生节点或历史，成功拖动或接线只形成一个可撤销事务。当前等待用户在复杂管路图中完成视觉与操作验收。

### 阶段 A 已实现待验收：制冷管路静态样式与方向

- 制冷管路首阶段已在编辑模式实现双层世界空间静态管道样式：主要线路为 `10px / 2px` 管体/内芯，辅助线路为 `4px / 1px`，两者共享带内阴影深色平头管体、圆头回路色内芯、`16px` 世界空间命中、普通弯头 `8px` 圆角与单向箭头缩放适配。制冷拱桥均为 `16 × 8px`，主要/辅助世界空间遮罩分别为 `18px / 12px`。下层平头直接止于图元锚点中心，共享物理区间由主要样式优先；三方向及以上分叉保持直角，避免圆角破坏连接语义。
- 管路方向分为内部定义方向、允许流向和实际流向三层。逻辑边的 `sourceNodeId → targetNodeId` 只提供稳定内部方向；现有 `flowDirection` 继续表达双向、正向或反向允许通行；未来运行态再派生正向、反向、停流或未知的实际流向。
- 节点没有方向。拆分子线和固化拐角时延续原线路的物理允许方向；移动、合并和自动重路由不得根据左右、上下、冷热类型、锚点名称或创建顺序猜测水流。
- 无真实遥测时，已使用确定性模拟 Provider：运行水泵出口作为闭环流量注入点，同一水泵入口作为回收点；冷却子线还可显式把一个物理端点配置为水流源头，向同一有效管网中其他可达的连接度为 1 的开放自由端注入。直接接线保持冷热类型隔离，设备内部按一次/二次回路族允许同侧冷热端传播且禁止 PHE 跨侧串水；当前按统一无量纲阻力求解闭合或开放网络的有符号视觉流量。死端、无源开路、停泵、零功率、无可达出口、关阀和逆单向约束保持静态，多驱动对冲区间按净流量决定方向。
- 水泵出入口在现有锚点编辑器中按专用素材资产级配置：资产标记为水泵，冷却锚点分别标记唯一入口和出口；全部实例继承角色，旋转不互换。配置缺失或类型不兼容不阻止静态编辑和保存，但该水泵不驱动模拟并返回诊断。通用图元首版不提供实例级水泵角色或端口覆盖。
- 制冷视觉模拟使用固定 `100 m³/h` 水泵/显式管路源头基准流量；水泵支持 `0–100%` 输出功率，显式源头当前固定为 `100%`。流量经等阻力网络分配并控制动画方向与速度，满足视觉流量守恒，但不计算压力、扬程、真实阻力、管径或其他工程水力。模拟运行态不进入项目 JSON、编辑历史或 dirty；水泵入口/出口角色、子线允许方向和源头端点属于持久化编辑配置。详细方案见 `COOLING_PIPELINE_DIRECTION_DESIGN_BRIEF.md` 与 `COOLING_VISUAL_FLOW_SIMULATION_DESIGN.md`。

2026-09-01 增量：母线接入点在用户口径中统一为“节点”，内部保留母线宿主约束。保存 offset 直接决定实际位置，路由不再自动滑移；节点可 hover、选择/框选、与图元和母线混合移动、沿母线单独移动、双击起线和删除，同一母线同一位置的接线复用一个节点。母线缩短不得越过节点，冲突时停止在约束位置并在单次手势中显示一条 Toast。该增量取代早期 tap 自动滑移与按数量压缩规则，不改变 Schema v29。

## 当前增量：电力母线

### 已确认目标

- 电力图纸支持独立母线对象；母线只保持水平或垂直，不产生折点，也不存在两个可接线端点。
- 母线以可拖入的线路工具创建，但不作为普通 SVG 图元或图元资产。
- 普通电力接线可以接入母线范围内任意 8px 网格点；同一母线上的全部支路天然连通。不同母线可以通过一条明确可见的普通电力子线互联，子线使用两个母线 tap 和一条普通线路边表达，不把母线直接隐式合并。
- 母线支持选择、移动、8px 步进长度调整、90° 旋转、删除和撤销/重做。保存的母线节点位置是实际位置；缩短不得越过节点，调整起点时反向更新 offset 以保持节点世界坐标，越界手势被约束并只显示一条汇总 Toast。
- 选中一条或多条母线后可批量修改颜色；连续颜色输入只预览，确认后单次提交，恢复默认时删除自定义颜色字段。已建立 tap 和当前候选接入点始终使用所属母线颜色。
- 母线可与普通图元一起被框选、显示独立选中态并进行整体移动或 90° 旋转；包含母线的混合选区不提供整体缩放。
- 普通接线未显式接入而正交穿过母线时始终由普通子线绘制拱桥表达不连通；共线重叠禁止。
- 母线节点固定在保存的合法 8px offset；用户可沿母线拖动或用方向键调整，同点接线复用一个拓扑节点。路由按完整路径长度和包含锚点出线方向的转折数选择折线路径，但不改变节点位置。
- 真实持久化电力节点作为一个或多个子线的端点主动落到唯一母线范围时，自动原位转换为母线宿主节点并接入；同点既有母线节点直接吸收，同母线网络同步合并。被动路由穿越没有真实节点时不接入，多母线交点无明确节点归属时拒绝变换。
- 母线节点的法向两侧接线共享同一个宿主节点；普通线路真正穿越母线的拱桥点继续禁止接入，被动交叉不生成节点。
- 母线默认没有文字标签；单选一条纯母线时可在右侧属性面板填写或清空标签、配置标签文字颜色，并通过独立开关隐藏或恢复当前母线的非空标签。颜色缺省为 `#B6B8B4`，支持 HEX、即时预览与恢复默认；标签使用固定 14px 世界字号，可绑定母线起点或终点并放在端点方向的垂直两侧：水平母线为上/下，垂直母线为左/右。标签沿所选端点向母线内侧展开并保持 8px 轴向 padding 与 8px 法向间距；单选后可拖动选择四种方位，文字保持水平且不参与拓扑、框选、吸附和线路障碍。

### 本轮边界

- 母线首版仅用于电力线路；可进入普通图元的混合框选、移动、旋转、复制粘贴和 Duplicate，但不进入图元缩放或锚点编辑器。母线与其连接对象同时位于选区时复制内部 tap 和逻辑接线；连向选区外对象的 tap 与支路不复制。
- 母线选中后可从空心候选 tap 发起普通子线；同一母线不能自连，不同母线必须通过显式普通线路边连接。

## 监控模式：已确认能力与首轮状态

- 监控模式与编辑器建立明确的运行时边界：完整项目先派生单张图纸、资产、连接、下探关系等只读视图，Switch/泵阀状态、外部供电和高频指标通过独立运行态上下文及可替换 Provider 注入。当前应用必须反向使用同一边界，后续另一个 React 项目可复用只读查看器并把下探接到自身导航；编辑 Store、dirty、历史、会话视口和随机读数不得成为跨项目运行时输入。阶段方案见 `MONITOR_RUNTIME_ARCHITECTURE.md`。
- 在一次接线图上呈现设备状态、告警和运行流向等动画反馈。
- 提供趋势、指标或状态统计图表。
- 支持遥测数据模拟，生成温度、功率、压力、流量、开关状态和告警等运行数据，以便在真实数据源接入前开发、演示和验证监控流程；不包含电气潮流、暂态或冷却水力等物理计算。
- 编辑文档状态与高频运行数据需要分层管理，避免监控刷新污染图纸历史记录或保存数据。
- 电流与冷却水流的移动虚线使用独立 WebGL 运行态覆盖层，复用包含拱桥的缓存显示路径；不得通过逐帧修改 SVG 路径、React 状态或业务路由实现动画。监控模式按物理区间区分流动与静止：静态 SVG 内芯直接把流动区间绘制为业务色、无流动区间绘制为原业务色压黑 50% 的最终不透明色，不在完整原色线之上叠加静态覆盖；WebGL 只叠加流动区间的移动虚线。播放暂停不改变流动资格。
- 运行态按线路类型与样式批量绘制，每帧只更新统一时间或 GPU Buffer；遥测更新、视口裁剪、后台暂停和减少动态效果策略见 `MONITOR_FLOW_ANIMATION_DESIGN.md`。
- 首轮监控模式以 Grid、Generator 和 Battery 为电力 Source，以算力 POD、动力 POD 和 FM 为 Target；未配置单向约束的线路不以创建顺序猜测业务方向，已配置单向的逻辑边只能顺箭头传播。每个 Source 图元独立计算到各可达 Target 的最短路径，再取全部 Source 路径并集，邻近 Source 不得抢占另一 Source 的较长有效路径；同一区间出现相反推导方向时不动画。无 Target 整链和死端支路不动画。Switch、2WV、CV 的 On/Off 保存于 Schema v23 图元快照并镜像到兼容运行态存储，可从编辑属性面板或监控画布控制；Off Switch 使其两侧相邻普通子线不显示流动动画，Off 2WV/CV 在作为制冷阀门时切断内部水路。Generator 运行/停机与 Battery 充电/放电对 Source 激活的门控尚待后续运行态增量。
- 设备层电力子图可把父图关联设备视为外部供电边界：只有关联父设备当前带电时，用户标记的子线入口端才成为显式 Source；若整张子图没有显式入口，则回退为母线首个接入点和明确单向的自由输入端。Cabinet 与明确单向的自由输出端成为 Target；Cabinet 的多个锚点分别作为独立终端，不在设备内部互联，双路都可达时两路同时动画，单路可达时只保留该路。监控模式单击已映射图元直接下探子图，结构、导航历史和播放状态保持只读会话语义；显式目标图纸 ID 优先，当前 POD A 在没有显式字段时按 Tap-off Unit A/B 与 UPS 左/右设备组约定映射。双向自由端不猜测方向，Battery-group 不自动取得 Source 资格。
- 显式入口供电的设备子图中，至少一个 tap 参与有效路径的自动方向母线应覆盖完整物理长度；同一已带电设备从该母线接入的其他明确单向入线也应动画。该补齐不得扩散到双向冗余线、Battery-group、普通环路、关断设备或方向冲突区间。
- 每个普通图元实例可配置最多 5 项数值型或文本型运行指标及独立显隐；编辑模式对数值取模拟范围中间值、对文本取首个正常候选，稳定预览组合标签且不刷新。监控模式进入时立即生成模拟值，之后每 30 秒更新一次；文本候选按正常 90、次要 6、重要 3、紧急 1 的等级权重抽样，使正常占绝大多数。数值型支持上限、下限和正常区间外阈值，文本型由候选状态直接指定等级；两类指标在次要、重要、紧急时只给数值或文本状态增加黄、橙、红紧凑背景与黑色文字，指标名称和单位保持原样且不带底色，正常数据保持透明背景和中性色。数值单位以半角括号紧跟指标名称，例如 `有功功率(kW)`，读数列只保留当前值；设备名称、运行数据整体、全部指标名称与单位分别控制显隐，关闭指标名称与单位后只收紧组合标签并保留读数或文本状态及异常数据背景。配置随图元保存和复制，预览值与当前模拟值不进入项目文档。
- 首轮电力与制冷 WebGL 移动虚线均已实现。制冷按运行水泵出口到同一水泵入口建立有效闭合管网，也允许显式冷却子线源头向其他可达开放自由端建立开放管网流量；两类驱动执行相同的直接接线类型、设备内部回路族、子线允许方向和阀门门控，普通阀门开启后双向，CV 开启后仅允许入口流向出口。当前按统一无量纲阻力求解多驱动与并联管网的有符号视觉流量，符号决定方向、绝对值决定速度。监控模式允许单选泵阀并通过右侧运行面板启停、开关和调节水泵 `0–100%` 输出功率，但图纸结构保持只读。监控画布保留主要 `10px / 2px`、辅助 `4px / 1px` 的管体/内芯层级，只在有效内芯区间用独立 `cooling` 样式批次复用电路的深色 `6px / 6px` 移动虚线；覆盖宽度使用对应世界空间内芯宽度并随 zoom 匹配，电力覆盖继续使用固定屏幕空间宽度。不复用电力 Source→Target 最短路径拓扑，也不模拟压力。

## 成功标准

以下为当前可验证成功标准：

- 用户能在画布中拖入图元，并通过单选、多选或框选完成旋转、移动、缩放和贴齐网格操作。
- 每个普通图元默认显示设备标识；单选后右侧属性面板提供独立开关，只隐藏或恢复当前图元且不影响其他图元或母线标签。显隐设置随图元复制、撤销/重做、JSON 和本地保存持久化；显示时，未选中或多选标签不接管指针，单选图元后可拖到画布坐标的上、右、下、左侧。自动布局只避让实际已连接锚点的出线区域，未连线锚点不改变默认候选方位，接线增删后按当前拓扑重新布局。
- 通用图元以默认灰色可改色虚线框、默认 `#121316` 且可独立改色的背景和框内白色设备标识呈现；右侧可分别修改虚线框颜色、背景颜色，以及吸附 8px 网格的宽度与高度，并通过默认开启的实例开关隐藏或恢复虚线描边。关闭描边不改变背景、标识、锚点、运行指标和两项已配置颜色。旋转后标识仍水平，长文本以省略号和旋转内框裁剪保证不溢出；设备运行指标仍在四侧显示并受既有运行数据及指标名称/单位开关控制。锚点编辑器中新建通用图元锚点时，默认类型随当前图纸系统选择，冷却图为“通用”、电力图为“电路”；已保存锚点类型由用户明确控制。
- 图元产生实际 8px 网格位移后才显示十字对齐区域；多选拖动时每个图元各自产生一组，重叠区域只统一着色一次。纵向带宽等于图元当前显示宽度，横向带高等于图元当前显示高度；结束或取消拖动后消失，且不修改项目数据。
- 多选整体缩放保持普通图元登记的逻辑宽高比、通用图元进入手势前的自定义宽高比和全部对象相对位置；多选整体旋转围绕选区中心以 90° 步进进行。两类变换提交后，每个图元的 X、Y、宽、高均为 8px 整数倍。
- 框选能严格包含完整母线，并允许一个或多个母线与图元形成混合选择；混合选择整体移动和旋转后，各对象仍贴合 8px 网格，母线保持水平或垂直且长度不变。
- 用户可通过 `Esc` 清空主画布选择，通过 `Command/Ctrl+C`、`Command/Ctrl+V` 和 `Command/Ctrl+D` 把全部已选图元与母线复制为新选择，并通过 `Command/Ctrl+X` 剪切后移动到同专业的另一张图纸，通过 `Command/Ctrl+S` 保存当前项目且不触发浏览器默认“保存网页”；选区内部接线关系同步复制并自动重路由，选区外支路不进入剪贴板。跨图纸副本落在目标当前视口中心，同图纸副本沿用固定网格偏移。
- 用户可用上、下、左、右方向键把全部已选图元与母线沿对应方向移动 8px；长按或快速连按时画面按帧响应，停止后只执行一次历史提交和正式线路重路由，一次撤销恢复整段连续移动。
- 画布不挂载标尺或鼠标 X/Y 坐标显示；自适应点阵、状态栏网格间隔与滚轮缩放保持一致，移除项不占用绘图空间或参与指针移动更新。
- 滚轮缩放后，当前可见间隔是能保持至少 8px 屏幕点距的最小 8px 世界单位倍数，状态栏同步显示 8、16、24、32px 等当前间隔。
- 仅使用缩放按钮、鼠标滚轮缩放、触控板捏合/双指平移、中键平移、空格+左键平移或切图自动适配时，项目文档、更新时间和 dirty 状态均不变化，顶部继续显示“已保存”；切换图纸或刷新后无需恢复上一次视口，进入目标图纸时自动居中看全其稳定业务内容。
- 在当前最大真实归档的 POD A 图纸中，25% 缩放下中键、空格+左键或触控板双指短距离平移不触发逐输入事件的 React 画布重渲染，SVG、点阵与监控流动层保持同一视口；中键基准机器帧时间 P95 约 16.8ms。长距离平移按 120px 屏幕距离低频刷新 overscan 裁剪集合，手势结束后同步最终会话视口。
- 中间画布无外层 padding、边框和圆角并铺满两侧栏之间的工作区；返回、编辑/播放、缩放、标题/路径和状态 HUD 均位于画布内部，按钮以外的 HUD 元素透明且靠近边缘，不形成新的布局层。
- 用户能新建、保存和重新打开浏览器本地项目，并通过 JSON 完成有校验的导入和导出，图纸层级及图元数据保持一致。
- 素材区分别只显示一个默认 Off 的 Switch、2WV 和 CV；旧项目中的 Switch On/Off 实例自动迁移到统一 `switch` 素材键，并保留自定义名称、实例属性和可合并锚点；既有 `2-wv`、`cv` 实例保持稳定键和锚点。
- 用户能从右侧属性面板流畅拖动颜色选择器并即时预览 Generator、Grid、MP、Transformer、Tap-off Unit 的单一实例颜色、通用图元彼此独立的虚线框颜色与背景颜色，以及 Switch、2WV、CV 各自独立的关/开状态颜色；编辑模式切换任一 On/Off 图元后立即显示对应素材和颜色。连续预览不写项目或触发线路重路由，最终颜色修改只占一个撤销步骤并随项目 JSON 和本地保存持久化；On/Off 状态本身随本地项目存档、JSON 导入导出和图元复制保留，状态切换不修改项目 dirty、更新时间或历史。
- 用户选中一条或多条母线、逻辑子线，或两者组成的线路混合选择后，可在右侧属性面板通过同一个应用内 HEX 选择器批量预览、提交和恢复颜色，不打开系统 RGB 面板；跨网络追加选择与网络主干展开后的逻辑边均正确生效，重新选择后显示已保存值，多色状态不伪装成默认色。母线 tap 与候选点同步所属母线颜色，整次批量修改只占一个撤销步骤，并随对象内部拓扑复制、项目 JSON 与本地保存持久化。
- 用户手动多选纯图元、纯母线或纯节点间子线后，可在右侧属性面板批量修改选区共同支持的标签显隐；图元与子线还可批量控制运行数据、指标名称与单位并用明确选择的整套模板覆盖指标，图元同一颜色模型可批量改色，Switch/2WV/CV 可批量修改关/开颜色和 On/Off。混合布尔值显示三态，混合指标不隐式合并；每次普通批量操作只占一个撤销步骤，每个目标指标 ID 独立，On/Off 继续不修改项目 dirty 或编辑历史。
- 用户单选独立逻辑子线后可填写、清空、隐藏和恢复该边标签；标签拖动可在源/目标端点和每个端点的两侧间切换，横向端点段对应上/下，纵向端点段对应左/右。路由变化后标签继续按所选端点与侧向贴合新的局部方向，且文字、显隐、端点和侧向随撤销/重做、内部拓扑复制、JSON 与本地保存持久化。
- 用户单选或纯子线多选后可把通行方向设为双向、起点→终点或终点→起点；混合方向正确回显为“多种方向”，批量修改只产生一次项目提交和一个撤销步骤，母线混合选择不误显示该字段。单向箭头始终位于对应逻辑目的端并随缩放保持固定屏幕尺寸。逆箭头的电力 Source→Target 路径不得进入动画，方向设置随撤销/重做、内部拓扑复制、JSON 与本地保存持久化，v15 及更早项目缺省迁移为双向。
- 画布空选时，右侧属性面板按图元、母线、子线列出当前实际颜色和使用数量；选择一个颜色后只全局替换同类别且当前颜色相同的对象，连续调整只做 SVG 原位预览，完成后形成一个可撤销历史事务。
- 用户能从素材 hover 编辑入口打开双栏锚点编辑器，在非角点的边缘 8px 网格点添加、跨四边移动和删除锚点，并在顶部修改名称与六种明确类型。
- 锚点修改即时应用且可撤销/重做；方向由边缘自动确定，项目保存、JSON 往返和旧版本迁移不会丢失锚点。
- 用户能从已使用或未使用的图元锚点、母线、自由节点或空白网格点创建合法接线；兼容图元锚点、母线、另一网络节点和普通子线都可作为终点。落到子线会在实际共享段创建或复用节点，并保留原逻辑线路属性；用户显式闭合同网络回路被允许，不兼容类型、同点自连、重复边和不同网络共线重叠会被拒绝。
- 同一锚点连接多个目标时，各逻辑边分别按最短、少转折和中点优先规则派生；从相同锚点出发或等价中点路线自然重合时形成无标记共同段，业务数据和画布均不出现固定分叉连接点。
- 用户可拖动任意普通子线段创建或调整节点；节点可单独或与图元/母线一起选择、移动、删除和 90° 旋转。共享节点的移动和按连接度删除对全部引用子线一致生效，恢复自动布线会正确清理路径引用和孤立点。
- 自由节点在编辑态 hover/选中时显示圆点，默认和监控模式无常驻标记。节点落到同一 8px 点时，同类型网络自动合并，不兼容类型整次回滚并提示；二连节点删除时局部恢复自动路由，三连及以上节点删除相关线路且不恢复主管。
- 图元或母线变换若使节点硬约束无解，整次变换被阻止且只出现一条汇总 Toast；项目数据、历史和线路几何不产生部分提交。没有节点约束的线路继续遵循最短、少转折和中点优先的默认自动路由。
- 拖动图元时线路端点逐帧跟随但不逐事件执行完整网络寻路，松手后只执行一次正式避障重路由；起线跟随以当前 8px 网格点为最小更新粒度，并在单个动画帧内合并重复输入。
- 在当前 67 图元、13 母线、73 逻辑边真实归档中，生产构建从未选中状态直接拖动已接线图元时，主线程不出现 50ms 长任务；正式路由在后台完成且旧任务结果不会覆盖新状态。
- 在当前最大真实归档的 125 图元、20 母线、67 网络、171 逻辑边场景中，移动一个已接线图元后的正式路由只重算受直接连接或空间走廊影响的网络，并复用其余线路；空闲时不挂载接线锚点，视口外静态对象不进入大图 SVG DOM。基准机器上的完整路由和增量路由耗时仅作回归对照，不作为跨设备固定承诺。
- 拉伸母线时线路与 tap 使用逐帧轻量几何预览，松手后才执行一次完整路由；鼠标进入终点图元或合法锚点时不得搜索图元内部的不可达坐标，应直接预览到边缘或目标锚点。
- 接线虚线不得因起终点距离增大而耗尽交互搜索预算后消失；远距离预览可以使用更强的朝向终点启发式，连接完成后的正式 Worker 路由仍按完整精确评分生成。
- 自动路由不穿过图元区域，除合法锚点过渡外只走 8px 正交网格；不同网络普通交叉以无拓扑节点的拱桥呈现。
- 拱桥使用默认 8×4px 真圆弧并通过 12px 局部画布色底衬与下穿线路分离；可见线路和透明命中路径使用同一拱桥几何，且不使用滤镜、阴影或逐交叉 DOM 节点。
- 通用网络的解析类型随当前专用端点变化；线路拓扑随 JSON 与 IndexedDB 持久化，图元变换后能稳定重新路由。
- 用户能创建和编辑电力母线；普通电力接线可在任意合法网格点接入，同一母线支路保持拓扑连通，未连接交叉以拱桥表达。
- 用户缩短带节点的母线时，手柄停在最外侧节点约束处并给出一条 Toast；母线与节点几何可作为一步撤销或重做，节点不被比例压缩或重排。
- 母线接线保持用户确认的节点位置，自动路由只在固定端点之间求最短少折路径；图元到图元的等长线路优先沿两端锚点的默认出线方向交汇，重复计算与重载结果稳定。
- 母线两侧接线落到同一 8px 网格点时复用同一个母线节点；不同宿主节点或图元锚点重合会阻止变换，未连接穿越点继续执行既有拱桥规则。
- 新建和旧项目母线默认无文字；用户填写母线标签后可在两个几何端点及各自垂直两侧形成的四种方位中显示，水平母线对应上/下，垂直母线对应左/右，并使用固定 14px 世界字号、8px 轴向 padding 和 8px 法向间距；标签颜色默认 `#B6B8B4` 且可按实例配置，清空文字后完全隐藏。右侧开关只控制当前母线，关闭时保留文字、颜色、端点和侧位；显隐、内容、颜色和方位均可撤销/重做并随复制、JSON 与本地保存持久化，但不产生可接线端子语义。
- 当长度、转折数和其他硬约束相同时，子线的折点组合优先接近两端中点，且不因同网络已有路径改变位置；结果保持确定性。
- 用户能从已选中母线发起普通子线连接另一条母线；两端 tap 联合滑移到最短少折位置，删除子线后网络按剩余路径正确拆分。
- 系统能把监控数据与图中设备可靠关联，并清晰表达设备状态与告警。
- 监控模式能在不修改图纸业务文档的前提下驱动状态动画和图表，并能在模拟数据与真实数据源之间替换。
- 电力移动虚线只出现在至少一个 Source 图元沿全部子线通行约束到达可达 Target 的最短业务路径上，其中 Source 为 Grid、Generator 或 Battery，Target 为算力 POD、动力 POD 或 FM；较近 Source 不隐藏其他 Source 的有效路径。闭合但无 Target 的整条链路、有效主干旁的死端支路、Off Switch 两侧、逆箭头路径及方向冲突区间均无动画，同一 Source 的等长有效路径同时保留。
- 监控模式中，电力普通子线、母线与制冷内芯按最终显示几何的物理区间区分流动和静止；无流动区间直接使用原业务色压黑 50% 的最终不透明色，部分流动逻辑边只替换静止部分且共享段不重复绘制。静态层下方不得保留会从抗锯齿边缘透出的完整原色内芯。暂停播放不改变流动资格，编辑模式业务色与管路样式不受影响。
- 制冷水流不复用电力最短 Source→Target 裁剪；系统把每台有效运行水泵作为出口注入、入口回收，按等阻力网络求解物理区间的有符号视觉流量。直接接线兼容与设备内部水路分开判断，CT/PHE 同一回路冷热端可贯通而 PHE 一二次侧隔离。无遥测验收使用固定、可复现的模拟状态，验证输出功率、停泵、关阀、单向约束、等价分流汇流、开路、并联水泵和净流向，不生成压力且不宣称工程水力精度。
- 用户能为单个图元或节点间子线配置、排序和删除最多 5 项数值或文本模拟运行指标，也能把明确选择的整套模板一次覆盖到手动多选的纯图元或纯子线，并分别控制对象名称、运行数据整体及全部指标名称与单位显隐；关闭名称与单位后所有读数或文本状态及异常数据背景继续显示。编辑模式组合标签立即用中间数值或正常文本状态稳定预览，监控组合标签每 30 秒更新。数值型正确执行三种阈值模式，文本型按候选等级正常优先抽样；两类指标只给异常数据使用黄/橙/红背景和黑色文字，标题与单位保持原样且无底色，正常数据保持透明中性，同时不因模拟值变化修改项目 dirty 或编辑历史。
- 绘图模型与监控模型具备可扩展性，能覆盖后续确认的 AIDC 电气设备和拓扑关系。
