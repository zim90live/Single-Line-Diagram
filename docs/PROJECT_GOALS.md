# 项目目标

最后更新：2026-08-18

## 愿景

创建一个面向 AIDC 场景的一次接线图绘制/监控系统，为电气一次系统的图形化建模、展示和运行监控提供统一工作界面。

## 当前已确认目标

1. 建设编辑、监控双模式的 AIDC 一次接线图系统。
2. 系统覆盖冷却、电力两套线路。
3. 每套线路支持多层级图纸，已明确的层级示例包括园区图、楼宇图、POD 图和设备图。
4. 支持一次接线图相关对象的运行监控，监控模式需要包含状态动画、趋势/指标图表和数据模拟能力。
5. 让项目目标、关键决策、任务状态和历史记录持续与实现同步，减少返工。

## 目标用户与交付形态

- 主要用户：AIDC 运维人员。
- 交付形态：Web 系统；第一阶段按桌面端编辑场景规划。

## 当前阶段

第一阶段基础编辑与图元锚点编辑器已于 2026-08-14 通过用户视觉与操作验收。线路连接已改为同锚点多线与网络级共享路径，固定子线分叉入口和可见分叉点已移除；电力母线、tap 自动滑移、锚点方向感知路由、不同母线普通子线互联和母线缩短时的 tap 受约束压缩均已完成实现和非视觉验证。图元与母线现可混合框选、移动、旋转，并统一支持复制、粘贴和 Duplicate；选区内两端对象均被复制的逻辑接线关系会同步生成新 tap、节点、边和网络，连向选区外对象的支路不复制。母线和逻辑子线现可在属性面板使用应用内 HEX 颜色控件改色；子线支持跨网络追加多选，并可与一条或多条母线组成线路混合选择，统一批量预览、提交或恢复颜色。网络主干选择会批量作用于网络内全部子线，多色选择明确显示“多种颜色”；母线 tap 与候选连接点继承所属母线颜色。空选属性面板按图元、母线、子线汇总当前画布实际颜色与使用数量，可一次替换同类同色对象；Switch 关/开颜色作为独立槽位汇总和替换。每个图元设备标识默认显示，单选图元后可在右侧属性面板独立隐藏或恢复；母线与独立逻辑子线均可填写可选文字标签，空值始终隐藏，非空标签也可通过当前对象的独立开关隐藏或恢复。子线标签绑定源或目标端点，并根据端点附近派生线段的方向放在横线的上/下侧或竖线的左/右侧。三类标签均保持水平世界空间文字，并支持各自既定的方位交互。图元拖动、母线拉伸、方向键连续移动与起线跟随的高频路径已改为逐帧合并和轻量几何预览；正式全图路由由 latest-wins Web Worker 异步生成派生快照，新接线使用即时临时路径，React render 和接线完成事件不再同步执行完整 A*。等长少折线路优先把拐点布置在端点中部；非连接交叉已使用带局部底衬的真圆弧拱桥。当前等待用户继续检查设备标识显隐与标签、母线与子线端点标签、混合选择、拖动/拉伸/方向键移动/终点悬停流畅度、共享路径、自动分叉位置、类型颜色、避障/拱桥以及母线相关效果。监控模式首轮已实现顶部模式 Tab、只读画布、Switch 独立自动保存、Grid 到算力/动力 POD 的业务拓扑定向、Off Switch 两侧相邻线路停流和 WebGL 深色移动虚线；编辑模式现也可通过右侧属性面板控制同一 Switch 运行态，关/开状态颜色分别配置。冷却业务方向、遥测模拟、图表和规模化性能基线仍待后续。

## 第一阶段：编辑系统

### 已确认范围

- 从素材区拖入图元。
- 图元单选、多选和框选；框选可同时包含母线。
- 图元旋转、移动和缩放。
- 多选时每个图元和母线显示选中态，并通过整体包围框一起移动和旋转；仅包含图元时继续支持整体缩放。
- 图元贴齐网格。
- 画布顶部与左侧显示标尺。
- 画布使用滚轮直接缩放、鼠标中键拖动平移；左侧图纸树节点保持单行。
- 拖动画布内图元或从素材区拖入图元时，显示贯穿画布的十字对齐区域，并跟随当前 8px 吸附位置。
- 新建、保存和打开项目。
- 撤销/重做、复制/粘贴、删除和键盘快捷键。主画布中方向键按对应方向以 8px 步进移动全部已选图元与母线；连续按键使用轻量预览并合并为一次历史提交。`Esc` 退出接线并清空图元、线路或母线选择；`Command/Ctrl+C`、`Command/Ctrl+V` 和 `Command/Ctrl+D` 统一作用于全部已选图元与母线；`Command/Ctrl+S` 在应用内全局保存当前项目。
- 使用 JSON 文件导入和导出项目。
- 图元素材由用户后续导入。
- 当前图元只使用 `src/assets/symbols/` 中登记的 SVG；插入尺寸采用 SVG 原始宽高。画布默认在每个图元旁显示独立的“设备标识”文字，单选图元后可在右侧属性面板独立隐藏或恢复；标签不增加背景或卡片外壳，也不计入图元尺寸、框选、吸附或线路避障，排布独立于主画布 8px 网格。
- 图元标签默认由系统在画布坐标的上、右、下、左四侧自动选择并避让锚点出线区域；用户单选一个图元后可拖动其标签改变方位，多选时标签不可选中或拖动。图元旋转不旋转标签，也不改变已选标签方位；设备标识内容继续只在右侧属性面板编辑。
- `SwitchOn.svg` 与 `SwitchOff.svg` 归为同一个 `Switch` 图元，缺省呈现 Off；编辑属性面板与监控画布共享同一 On/Off 运行态。状态只决定素材与当前颜色槽，不写入编辑历史或项目 JSON，并独立自动保存。
- 2WV、CV、Generator、Grid、MP、Transformer 支持在右侧属性面板修改单一图元实例颜色；Switch 分别配置关/开状态颜色。色块入口展开应用内 HEX 选择器，不调用无法控制 RGB/HEX 模式的系统颜色面板。连续调整只进行轻量画布预览，确认后单次写入项目与撤销历史。其他图元继续保持原始 SVG 配色。
- 未选择对象时，右侧属性面板按图元、母线、子线显示当前画布实际使用的全部颜色及对象数量。Switch 关/开颜色按两个独立图元颜色槽列出；点击任一颜色可全局替换同类别、同颜色槽、同当前颜色的对象。默认色也参与汇总，原始 SVG 配色且不支持实例改色的图元不进入图元颜色组。
- 素材专业分类以当前目录登记为准：CPD 属于冷却；FM、Cabinet、算力 POD、动力 POD 属于电力。
- POD 图元需要以高于单台设备的抽象层级表达：算力 POD 表示 AI 计算单元；动力 POD 表示面向大楼制冷系统、电梯等其他设备的电力/制冷基础设施单元。当前视觉方案试行英文缩写加立方体，待用户验收。
- 画布以 8px 世界单位为最小网格并使用单一样式点阵呈现；所有点大小、颜色和透明度一致。滚轮缩小时依次使用 8、16、24、32px 等 8px 倍数作为当前可见间隔，标尺与点阵使用同一个间隔和世界坐标原点。图元移动和尺寸仍贴合 8px 最小网格，缩放保持原始宽高比并采用宽高同时落网格的离散步进，旋转以 90° 为最小单位。

### 已确认工程与界面基线

- 沿用 AIDC 项目的二维编辑架构：Three.js / React Three Fiber 正交顶视 WebGL 场景、GLSL 网格和 SVG 交互覆盖层。
- 沿用 AIDC 项目的 UI 设计系统：以 typed Token / Recipe、真实 React 基础组件和确定性生成 CSS 为唯一视觉真源；不继续使用 Ant Design 作为界面组件基线。
- 复用成熟交互模式和必要代码时复制、裁剪到本项目，不建立运行时跨项目依赖。
- 保留本项目独立的业务文档、Zod 校验、Dexie/IndexedDB 存储和 JSON 导入导出边界。

### 第一阶段后置项状态

- 线路连接和线路管理不属于第一阶段首轮实现；第一阶段现已验收通过，可以开始开展。
- 监控模式不属于第一阶段。

## 当前增量：图元锚点编辑器

### 已确认目标

- 支持为图元添加接线锚点，为后续线路连接提供端点。
- 锚点编辑画布使用 8px 最小网格。
- 锚点只能放置在 8px 网格点上。
- 锚点定义属于图元资产模板，同一资产的所有画布实例自动继承。
- 锚点只能放置在图元原始尺寸的边缘网格点上；出线方向由所在边缘唯一确定为垂直向外，用户不可修改。
- 锚点类型必须明确。电路使用单一电路类型；冷却使用一次回路冷、一次回路热、二次回路冷、二次回路热、通用五种类型。
- 图元实例缩放或旋转时，锚点随图元几何变换；缩放后的锚点允许不落主画布 8px 网格，后续线路从实际端点出发并处理网格路由。
- 图元锚点编辑弹窗中的合法修改即时应用到当前项目；弹窗不设置取消或应用按钮，仅通过右上角关闭按钮退出编辑。
- 图元锚点编辑器自身只负责资产级锚点定义与编辑；线路连接使用这些稳定定义，并在下方“线路连接与管理”增量中独立实现。

### 已确认边界

- 图元四个角不允许放置锚点。
- 锚点名称可编辑；稳定 ID、坐标、系统派生方向和类型为必需字段。
- 锚点定义随项目 JSON 与 IndexedDB 持久化，SVG 源文件不写入锚点元数据。

## 当前增量：线路连接与管理

### 已确认目标

- 配置了锚点的图元在 hover 时显示可用接线锚点；点击锚点开始接线，临时线路随鼠标正交增长，点击兼容图元锚点或母线完成。同一图元锚点允许重复发起或接收多条线路。
- 线路类型包括电力、一次回路冷/热、二次回路冷/热和通用；通用冷却网络在接入专用类型后整体解析为该类型，失去最后一个专用端点后恢复通用。
- 除图元缩放导致的非网格锚点过渡段外，线路只沿 8px 网格水平或垂直行走；系统自动选择避开图元区域的最短路径，并以较少转折作为次级目标。
- 长度和转折数相同的正交路径优先让拐点靠近起点与终点的中部，避免折点无必要地贴近任一端。
- 不同线路网络允许正交交叉但默认不连通，后创建线路使用拱桥表达跨越；不同网络共线重叠禁止。
- 非连接交叉的拱桥采用紧凑的真圆弧和加粗的局部画布色底衬；孤立拱桥默认占用 8px 路径跨度并抬高 4px，底衬为 12px 屏幕线宽。拱桥只属于派生显示几何，不改变线路拓扑或项目 JSON。
- 普通线路不提供接线入口。系统按整个连通网络联合寻路，同一锚点的多条线路自动合并共同路径并选择派生分叉位置；派生分叉不保存、不显示连接点，也不可交互。
- 点击独立支路选择对应逻辑连接；点击多条连接共用的主干选择整个线路网络。删除逻辑连接或网络后按剩余端点关系重新路由。
- 选中独立逻辑子线后可修改该边颜色并在重新选择后回显保存值；`Shift` / `Ctrl` / `Command` 单击可跨网络追加或移除逻辑子线，网络主干会先展开为网络内逻辑边参与选择。子线可与母线共同保留在一个线路混合选择中，通过同一颜色字段批量修改。选择内存在不同颜色时显示“多种颜色”，连续颜色输入只预览，确认后单次提交。
- 单选一条独立逻辑子线后可在右侧属性面板填写或清空可选标签，并通过实例开关隐藏或恢复非空标签。标签缺省位于目标端点的负侧；单选后可拖动到源/目标端点，并在端点附近横线的上/下侧或竖线的左/右侧切换。文字沿端点线段向子线内侧展开：横向使用左/右对齐与水平 padding，纵向使用顶/底对齐与垂直 padding，不越过子线端点。标签位置随派生路由方向更新，不保存折点坐标。
- 线路支持选择、删除、撤销/重做；图元变换后自动重新路由，删除图元时清理关联支路和孤立拓扑。
- 正式网络路由在 Web Worker 中异步计算并采用 latest-wins 调度；交互和提交期间显示稳定快照的轻量预览，新建边先显示接线预览路径，最终结果到达后再无阻塞替换。

### 本轮边界

- 线路业务数据采用连通网络、图元锚点/母线 tap 节点和端点逻辑边，不保存派生分叉或 SVG 路径命令。
- 本轮不支持手动拖动折点、任意中段/自由位置线路标签、独立选择线路后复制粘贴、监控动画或服务端协作；独立子线的受约束端点标签已支持，随多选对象复制其内部逻辑接线关系时一并保留。

## 当前增量：电力母线

### 已确认目标

- 电力图纸支持独立母线对象；母线只保持水平或垂直，不产生折点，也不存在两个可接线端点。
- 母线以可拖入的线路工具创建，但不作为普通 SVG 图元或图元资产。
- 普通电力接线可以接入母线范围内任意 8px 网格点；同一母线上的全部支路天然连通。不同母线可以通过一条明确可见的普通电力子线互联，子线使用两个母线 tap 和一条普通线路边表达，不把母线直接隐式合并。
- 母线支持选择、移动、8px 步进长度调整、90° 旋转、删除和撤销/重做。缩短时已有 tap 按原有顺序随长度成比例压缩并保持互不重叠的 8px 网格位置；最短长度为 `max((不同 tap 数 - 1) × 8px, 8px)`，同一 tap 接多条边仍只计一个连接点。
- 选中一条或多条母线后可批量修改颜色；连续颜色输入只预览，确认后单次提交，恢复默认时删除自定义颜色字段。已建立 tap 和当前候选接入点始终使用所属母线颜色。
- 母线可与普通图元一起被框选、显示独立选中态并进行整体移动或 90° 旋转；包含母线的混合选区不提供整体缩放。
- 普通接线未显式接入而正交穿过母线时使用拱桥表达不连通；共线重叠禁止。
- 母线 tap 默认允许沿母线自动滑移到最优合法 8px 位置；路由按完整路径长度和包含锚点出线方向的转折数选择结果。
- 母线接入占用按法向两侧分别判断：位于母线相反两侧的接线可共享同一个派生 8px 接入位置；同侧接线仍需避让，普通线路真正穿越母线的拱桥点继续禁止接入。
- 母线默认没有文字标签；单选一条纯母线时可在右侧属性面板填写或清空标签，并通过独立开关隐藏或恢复当前母线的非空标签。非空且开启的标签只能放在母线起点或终点的外侧并与端点保持 8px 视觉间距，单选后可拖动切换端点，文字保持水平且不参与拓扑、框选、吸附和线路障碍。

### 本轮边界

- 母线首版仅用于电力线路；可进入普通图元的混合框选、移动、旋转、复制粘贴和 Duplicate，但不进入图元缩放或锚点编辑器。母线与其连接对象同时位于选区时复制内部 tap 和逻辑接线；连向选区外对象的 tap 与支路不复制。
- 母线选中后可从空心候选 tap 发起普通子线；同一母线不能自连，不同母线必须通过显式普通线路边连接。

## 监控模式：已确认能力与首轮状态

- 在一次接线图上呈现设备状态、告警和运行流向等动画反馈。
- 提供趋势、指标或状态统计图表。
- 支持遥测数据模拟，生成温度、功率、压力、流量、开关状态和告警等运行数据，以便在真实数据源接入前开发、演示和验证监控流程；不包含电气潮流、暂态或冷却水力等物理计算。
- 编辑文档状态与高频运行数据需要分层管理，避免监控刷新污染图纸历史记录或保存数据。
- 电流与冷却水流动画使用独立 WebGL 运行态覆盖层，复用包含拱桥的缓存显示路径；不得通过逐帧修改 SVG 路径、React 状态或业务路由实现动画。
- 运行态按线路类型与样式批量绘制，每帧只更新统一时间或 GPU Buffer；遥测更新、视口裁剪、后台暂停和减少动态效果策略见 `MONITOR_FLOW_ANIMATION_DESIGN.md`。
- 首轮监控模式以 Grid 为电力 Source、算力 POD 和动力 POD 为 Target；线路创建顺序不代表业务方向。Switch On/Off 保存于独立运行态存储，并可从编辑属性面板或监控画布控制；Off 时与该 Switch 直接相邻的两侧普通子线均不显示流动动画，On 后恢复拓扑传播。
- 首轮已实现电力 WebGL 移动虚线；冷却 Source/Target 尚未定义，因此不得仅凭接线方向或锚点名称猜测水流方向。

## 成功标准

以下为当前可验证成功标准：

- 用户能在画布中拖入图元，并通过单选、多选或框选完成旋转、移动、缩放和贴齐网格操作。
- 每个普通图元默认显示设备标识；单选后右侧属性面板提供独立开关，只隐藏或恢复当前图元且不影响其他图元或母线标签。显隐设置随图元复制、撤销/重做、JSON 和本地保存持久化；显示时，未选中或多选标签不接管指针，单选图元后可拖到画布坐标的上、右、下、左侧并避让锚点出线区域。
- 图元产生实际 8px 网格位移后才显示十字对齐区域；多选拖动时每个图元各自产生一组，重叠区域只统一着色一次。纵向带宽等于图元当前显示宽度，横向带高等于图元当前显示高度；结束或取消拖动后消失，且不修改项目数据。
- 多选整体缩放保持各图元原始宽高比和相对位置；多选整体旋转围绕选区中心以 90° 步进进行。两类变换提交后，每个图元的 X、Y、宽、高均为 8px 整数倍。
- 框选能严格包含完整母线，并允许一个或多个母线与图元形成混合选择；混合选择整体移动和旋转后，各对象仍贴合 8px 网格，母线保持水平或垂直且长度不变。
- 用户可通过 `Esc` 清空主画布选择，通过 `Command/Ctrl+C`、`Command/Ctrl+V` 和 `Command/Ctrl+D` 把全部已选图元与母线偏移固定网格距离复制为新选择，并通过 `Command/Ctrl+S` 保存当前项目且不触发浏览器默认“保存网页”；选区内部接线关系同步复制并自动重路由，选区外支路保持不变且不进入副本。
- 用户可用上、下、左、右方向键把全部已选图元与母线沿对应方向移动 8px；长按或快速连按时画面按帧响应，停止后只执行一次历史提交和正式线路重路由，一次撤销恢复整段连续移动。
- 画布顶部与左侧标尺能与画布的平移、缩放和网格保持一致；标尺刻度直接对应当前自适应点阵间隔。
- 滚轮缩放后，当前可见间隔是能保持至少 8px 屏幕点距的最小 8px 世界单位倍数，状态栏同步显示 8、16、24、32px 等当前间隔。
- 用户能新建、保存和重新打开浏览器本地项目，并通过 JSON 完成有校验的导入和导出，图纸层级及图元数据保持一致。
- 素材区只显示一个默认 Off 的 Switch；旧项目中的 Switch On/Off 实例自动迁移到统一 `switch` 素材键，并保留自定义名称、实例属性和可合并锚点。
- 用户能从右侧属性面板流畅拖动颜色选择器并即时预览 2WV、CV、Generator、Grid、MP、Transformer 的实例颜色，以及 Switch 独立的关/开状态颜色；编辑模式切换 Switch 状态后立即显示对应素材和颜色。连续预览不写项目或触发线路重路由，最终颜色修改只占一个撤销步骤并随项目 JSON 和本地保存持久化；状态切换独立保存且不修改项目 dirty 或历史。
- 用户选中一条或多条母线、逻辑子线，或两者组成的线路混合选择后，可在右侧属性面板通过同一个应用内 HEX 选择器批量预览、提交和恢复颜色，不打开系统 RGB 面板；跨网络追加选择与网络主干展开后的逻辑边均正确生效，重新选择后显示已保存值，多色状态不伪装成默认色。母线 tap 与候选点同步所属母线颜色，整次批量修改只占一个撤销步骤，并随对象内部拓扑复制、项目 JSON 与本地保存持久化。
- 用户单选独立逻辑子线后可填写、清空、隐藏和恢复该边标签；标签拖动可在源/目标端点和每个端点的两侧间切换，横向端点段对应上/下，纵向端点段对应左/右。路由变化后标签继续按所选端点与侧向贴合新的局部方向，且文字、显隐、端点和侧向随撤销/重做、内部拓扑复制、JSON 与本地保存持久化。
- 画布空选时，右侧属性面板按图元、母线、子线列出当前实际颜色和使用数量；选择一个颜色后只全局替换同类别且当前颜色相同的对象，连续调整只做 SVG 原位预览，完成后形成一个可撤销历史事务。
- 用户能从素材 hover 编辑入口打开双栏锚点编辑器，在非角点的边缘 8px 网格点添加、移动和删除锚点，并在顶部修改名称与六种明确类型。
- 锚点修改即时应用且可撤销/重做；方向由边缘自动确定，项目保存、JSON 往返和旧版本迁移不会丢失锚点。
- 用户能从已使用或未使用的图元锚点创建合法接线；兼容类型可完成，不兼容类型和不同网络共线重叠会被拒绝，普通子线不能作为接线目标。
- 同一锚点连接多个目标时，自动路由复用共同路径并随端点变化重新选择无标记分叉位置；业务数据和画布均不出现固定分叉连接点。
- 拖动图元时线路端点逐帧跟随但不逐事件执行完整网络寻路，松手后只执行一次正式避障重路由；起线跟随以当前 8px 网格点为最小更新粒度，并在单个动画帧内合并重复输入。
- 在当前 67 图元、13 母线、73 逻辑边真实归档中，生产构建从未选中状态直接拖动已接线图元时，主线程不出现 50ms 长任务；正式路由在后台完成且旧任务结果不会覆盖新状态。
- 拉伸母线时线路与 tap 使用逐帧轻量几何预览，松手后才执行一次完整路由；鼠标进入终点图元或合法锚点时不得搜索图元内部的不可达坐标，应直接预览到边缘或目标锚点。
- 接线虚线不得因起终点距离增大而耗尽交互搜索预算后消失；远距离预览可以使用更强的朝向终点启发式，连接完成后的正式 Worker 路由仍按完整精确评分生成。
- 自动路由不穿过图元区域，除合法锚点过渡外只走 8px 正交网格；不同网络普通交叉以无拓扑节点的拱桥呈现。
- 拱桥使用默认 8×4px 真圆弧并通过 12px 局部画布色底衬与下穿线路分离；可见线路和透明命中路径使用同一拱桥几何，且不使用滤镜、阴影或逐交叉 DOM 节点。
- 通用网络的解析类型随当前专用端点变化；线路拓扑随 JSON 与 IndexedDB 持久化，图元变换后能稳定重新路由。
- 用户能创建和编辑电力母线；普通电力接线可在任意合法网格点接入，同一母线支路保持拓扑连通，未连接交叉以拱桥表达。
- 用户缩短带 tap 的母线时不会被旧 tap 位置阻挡；tap 保持拓扑身份和顺序并压缩到合法 8px 网格点，母线与 tap 可作为一步撤销或重做。
- 母线接线能把 tap 自动滑移到最短且少转折的位置；图元到图元的等长线路优先沿两端锚点的默认出线方向交汇，重复计算与重载结果稳定。
- 母线两侧的接线投影到同一 8px 网格点时可从相反法向共点接入；同侧接线和未连接穿越点继续执行既有避让规则。
- 新建和旧项目母线默认无文字；用户填写母线标签后只在两个几何端点之一的外侧显示并保持 8px 视觉间距，清空后完全隐藏。右侧开关只控制当前母线，关闭时保留文字与端点方位；显隐、内容和方位均可撤销/重做并随复制、JSON 与本地保存持久化，但不产生可接线端子语义。
- 当长度、转折数和其他硬约束相同时，子线的折点组合优先接近两端中点，结果保持确定性。
- 用户能从已选中母线发起普通子线连接另一条母线；两端 tap 联合滑移到最短少折位置，删除子线后网络按剩余路径正确拆分。
- 系统能把监控数据与图中设备可靠关联，并清晰表达设备状态与告警。
- 监控模式能在不修改图纸业务文档的前提下驱动状态动画和图表，并能在模拟数据与真实数据源之间替换。
- 绘图模型与监控模型具备可扩展性，能覆盖后续确认的 AIDC 电气设备和拓扑关系。
- 关键产品与技术决策可追溯，活动 TODO 与实际进度一致。
