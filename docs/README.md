## 同步流程

1. 开工前：阅读项目目标、有效关键决策和当前 TODO。
2. 执行中：发现新约束、范围变化或冲突时，先提醒用户并澄清方向。
3. 完成后：更新 TODO；如目标或决策发生变化，同时更新对应文档。
4. 阶段结束：将不再适合留在活动文档中的详细记录移入 `archive/`，并保留日期和来源。

## 状态约定

- TODO 状态：`待办`、`进行中`、`阻塞`、`已完成`、`已取消`。
- 决策状态：`提议`、`已接受`、`已取代`、`已废止`。
- 优先级：`P0` 必须立即处理，`P1` 核心近期工作，`P2` 后续重要工作，`P3` 候选优化。
