# 手动多选批量属性编辑设计简报

最后更新：2026-09-02

## 目标

让运维人员先在画布中手动选中多个同类对象，再从既有右侧属性面板一次修改共同属性，减少重复配置工作。首版不提供按类型自动查找、跨图纸选择、规则选择器或独立弹窗。

## 支持范围

- 图元：标签显隐、运行数据显示、指标名称与单位、整套运行指标配置；同一颜色模型下支持实例颜色，Switch、2WV、CV 还支持关/开颜色和运行状态。
- 子线：标签显隐、运行数据显示、指标名称与单位、整套运行指标配置，以及既有颜色、方向、层级和冷却线路级别。
- 母线：标签显隐和既有颜色。
- 图元、母线、子线或节点组成的异类混合选区继续显示摘要；首版不尝试跨数据集合合并含义不一致的属性。

## 交互规则

- 所选对象值一致时显示实际值；布尔值不一致时 switch 使用 `mixed` 三态，点击后统一设为开启，再次点击按普通开关工作；颜色不一致时显示“多种颜色”。
- 只修改用户实际操作的字段，未操作字段保持每个对象原值。
- 颜色沿用应用内 HEX 控件。连续拖动只做 SVG 原位预览；取消或选择变化时恢复各对象原值；确认后整组选区只形成一个项目历史事务。
- 标签、运行数据和指标标题开关点击后直接批量提交，整次只占一个撤销步骤。

## 指标模板覆盖

- 批量指标编辑采用整套模板替换，不按名称、单位或数组位置合并。
- 若所有对象的指标结构一致（比较时忽略指标和文本候选 ID），直接以共同模板进入草稿。
- 若结构不同，用户必须明确选择某个已选对象作为模板来源，或选择空白配置；系统不得隐式选择第一个对象或自动拼接。
- 草稿只在点击“应用到 N 个对象”后提交。每个目标对象分别重建全部指标 ID 和文本候选 ID，避免模拟读数、告警或后续编辑串对象；整次覆盖只形成一个撤销步骤。

## 运行状态边界

- “运行状态”适用于 Switch、2WV、CV 的 On/Off；它与“显示运行数据”“显示指标名称与单位”两个运行指标显示开关同时属于本批量能力。
- 批量 On/Off 先一次更新当前会话和画布状态，再在同一个 IndexedDB 事务中写入运行态镜像与项目快照。
- 与单对象切换一致，运行状态不修改项目 `dirty`、`updatedAt` 或编辑历史；存储失败时整批恢复原状态。

## 性能与历史

- 所有普通批量属性直接映射一次文档提交，禁止循环调用单对象更新接口。
- 指标和标签等非几何属性不得主动改变线路端点、途径点或路由参数；路由层可复用既有显示几何。
- 不增加画布常驻 DOM、工具栏或弹窗；只有多选属性面板挂载批量草稿编辑器。

## 验收

- 手动多选两个同类图元、两条子线或两条母线后，右侧出现对应共同属性；异值有明确混合态。
- 任一批量普通属性修改只需一次撤销即可整体恢复，并保持其他字段不变。
- 不同指标配置必须先选择来源；应用后每个对象内容一致、ID 不同，重新选择后可独立生成读数。
- Switch、2WV、CV 混合 On/Off 可一键统一，刷新后状态保留，但顶部保存状态不变化。
- 多对象颜色预览可取消；确认后颜色持久化且不产生逐对象历史步骤。
