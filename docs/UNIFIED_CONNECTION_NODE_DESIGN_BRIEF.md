# 统一连接节点与节点起线设计简报

最后更新：2026-08-25
状态：已实现，待用户视觉与操作验收

## 1. 功能摘要

把现有“途径点”和“分流节点”统一为同一种用户对象与数据对象：**节点**。节点不保存固定角色；系统根据当前物理连接度数派生它是路径上的中间点，还是多支路交汇点。

该增量同时允许用户从任意节点继续画线，以同一套对象模型表达手动改线、主管分支、支管汇流和后续复杂冷却管路。普通显示画面与监控模式不增加常驻标记，编辑模式只在节点 hover 时显示圆点和起线提示。

## 2. 主要用户动作

- 单击节点：选择节点；配合 `Shift` / `Ctrl` / `Command` 追加或移除选择。
- 拖动节点：移动节点并让全部邻接物理线段重新路由；节点仍吸附 8px 网格。
- 双击节点：从该节点开始接线；提示文案为“**双击从节点接线**”。
- `Delete` / `Backspace`：按节点当前连接度执行删除语义。
- 框选：节点可与图元、母线和其他节点一起进入选区；混合选区继续支持移动和 90° 旋转，含节点选区不支持整体缩放。

手势分配避免单击选择与起线竞争，也保留拖动前先选中对象的常见编辑器习惯。双击仅在编辑模式生效；监控模式维持只读。

## 3. 设计方向

- 继续使用中性、克制、画布优先的现有界面，不增加常驻工具栏、独立节点模式或特殊分叉图标。
- 未选中且未 hover 的节点不显示额外视觉；节点已有连接仍只由线路几何表达。
- 编辑 hover 时显示固定屏幕尺寸的空心圆，并显示“**双击从节点接线**”；可接线状态沿用既有兼容色与候选反馈。
- 选中态沿用现有点对象的选择反馈；多选时不重复显示说明文本。
- 监控模式不显示节点圆点，流动动画直接穿过物理线段。

## 4. 拓扑与数据模型

### 4.1 单一节点概念

- 用户界面、帮助文案、属性反馈和后续文档统一使用“节点”，不再并列使用“途径点”“交汇点”或“分流节点”。
- 自由坐标连接点在数据层也统一为一种稳定节点实体，保存 `id`、8px 网格坐标和所属连接网络；不持久化 `waypoint` / `junction` 角色字段。
- 图元锚点节点和母线 tap 仍是具有宿主约束的端点节点；本简报中的“节点”主要指用户可在画布上直接选择和移动的自由坐标节点。宿主端点不会因为连接度变化而失去其锚点或 tap 语义。

### 4.2 角色按物理连接度派生

连接度按展开逻辑线路后、实际邻接该节点的**物理子线段数量**计算，而不是按底层保存记录数量或视觉重叠条数猜测。

- 连接度为 1：开路端点。它由持续式线路绘制工具显式生成，可保存、编辑和继续接线。
- 连接度为 2：路径节点。它表达手动途径或主管中的中间转折/约束。
- 连接度大于等于 3：交汇节点。它表达真实分流、汇流或多支路连接。
- 自由节点连接度为 0：提交规范化时自动清理；图元锚点、母线 tap 等宿主端点不受该规则影响。

节点的角色可随画线、断开、合并和删除即时变化。例如三支路节点断开一条支路后会自然降为路径节点，不需要迁移对象类型。

### 4.3 逻辑线路与物理线段分层

- 节点不是属性容器；颜色、单向通行、冷却主要/辅助角色等线路属性属于相邻节点之间的子线段边。
- 每两个相邻持久化节点之间保存一条独立 `ConnectionEdge`，并以稳定边 ID 作为选择、删除和批量属性的最小单位；自动路由继续负责该区间内部的正交避障与派生折点。
- 同一旧逻辑连接拆出的子线段通过可选 `logicalConnectionId` 保留组关系，仅用于恢复自动布线时识别可收缩的二连路径节点；标签只保留在其配置端点所在的一段，不在各段重复。
- 自动路由折点没有稳定 ID，不会仅因显示路径转弯而拆边；用户拖动折点、从折点起线或把接线落到该点后，它才固化为节点和新的子线段边界。

## 5. 从节点起线

- 双击任意自由节点进入既有接线会话，起点类型继承节点所属网络解析后的线路类型。
- 终点可为兼容图元锚点、母线、现有节点或兼容子线。落到子线时创建或复用节点；节点精确碰撞时沿用自动合并规则。
- 新建逻辑线路默认双向通行，并使用对应线路类型的默认颜色；后续可通过既有右侧属性面板批量修改。
- 禁止连接到自身；禁止创建同一连通网络内没有明确业务语义的闭环。失败时取消本次接线并使用一条汇总 Toast，不产生部分节点、线段或历史记录。
- `Esc` 取消接线；接线预览、兼容判断、8px 吸附、避障和 Worker 正式路由沿用现有机制。

## 6. 移动、合并与删除

### 移动

- 拖动单个节点会移动该节点，并对全部邻接区间做轻量预览；松手后一次正式重路由和一次历史提交。
- 节点与图元、母线共同选择时，随选区一起移动或绕选区中心按 90° 旋转。
- 任何邻接区间无合法解时取消整个变换，只显示一条汇总 Toast，不做部分提交。

### 合并

- 两个或多个兼容节点精确落在同一 8px 坐标时自动合并为一个节点，并把全部邻接物理线段重连到保留节点。
- 被本次编辑移动的真实电力节点精确落到唯一母线范围时，节点保留原 ID 和全部邻接子线并原位转换为母线宿主节点；同点已有母线节点时直接吸收，同母线网络同步合并。该规则适用于开路端点、二连路径节点和分流节点。没有真实节点的自动路由穿越不触发，多母线交点无明确宿主时取消整次变换。
- 自由节点与已连接图元锚点精确重合时，由锚点吸收自由节点并保留其宿主端点身份；相邻逻辑边重连到锚点，同坐标路径引用和零长度物理区间同步清理。拖动端部子线离开图元锚点时，手动节点沿锚点进出方向向线路内部收进一格，保存为锚点引出点，避免自动路由生成短回折线头。把拖出的子线段拖回原路径或锚点过渡位置后，系统应删除本次手动段节点、重路由并迭代回收造成物理路径立即反向的独占节点，直至恢复无折返的自动连接；逻辑端点、共享节点和分支节点不回收。
- 合并后产生的自环、重复退化线段、悬空边和孤立节点必须在同一事务内清理。
- 网络类型不兼容时取消整次操作，并保留合并前状态。

### 删除

- 删除连接度为 2 的路径节点：收缩该节点，移除两条邻接物理线段，并由一个自动路由区间连接原来的两个邻居；等价于删除该途径约束并恢复这一局部的自动布线。
- 删除连接度大于等于 3 的交汇节点：删除节点及全部邻接物理线段，不自动猜测应该恢复哪一条主管。
- 删除及规范化始终作为一个可撤销事务；撤销应完整恢复节点、线路属性、相邻线段和原路由约束。

## 7. 关键状态

- **默认**：没有常驻节点标记，只显示线路。
- **节点 hover**：显示空心圆和“双击从节点接线”。
- **节点选中**：显示选择反馈，可拖动、删除或加入混合选择。
- **节点起线中**：复用现有临时正交线路、兼容目标和非法目标反馈。
- **拖动预览**：邻接线路使用轻量几何；合法时显示候选路径，不合法时显示冲突反馈。
- **监控模式**：节点不可交互且不显示提示；动画按物理拓扑和单向约束连续通过。

## 8. 兼容与迁移

- 项目当前 Schema 已升级至 v28。自由坐标点继续保存为 `ConnectionNode { kind: "node", x, y }`；持久化节点直接作为相邻 `ConnectionEdge` 的端点，正常保存不再依赖一条边跨越多个 `routeNodeIds`。Schema v27 允许持续绘线工具生成连接度为 1 的自由端点和显式闭环；v28 只增加节点间边的标签运行指标配置，不改变节点拓扑。
- 现有 `Diagram.routeWaypoints`、`ConnectionEdge.routeWaypointIds`、`routeNodeIds` 与旧 `junction` 节点会在载入时迁移为统一节点及相邻节点边；v1–v27 均纳入迁移白名单。
- 迁移必须保留坐标、颜色、标签、显隐、单向通行、网络类型、复制语义和有效监控拓扑。
- 载入旧缓存时继续执行 KD-075 的自环、悬空边和孤立节点修复；统一后不得重新保存带角色冲突的双模型数据。
- JSON 导入导出、IndexedDB、撤销/重做、复制、Duplicate、跨图纸粘贴、Worker 与主线程降级路径必须使用同一节点语义。
- 混合选区旋转后的自由节点必须重新吸附 8px 网格。受历史旋转缺陷影响的当前版本缓存，在正式校验前仅把编辑器生成的 `route-waypoint-*`、`connection-node-*` 有限坐标吸附到最近网格；其他越网格节点继续报错。

## 9. 验收标准

- 现有途径点和分流节点在界面中都只称“节点”，旧项目打开后位置和有效拓扑不变。
- 单击、拖动、双击三种手势分别稳定执行选择、移动和起线，互不误触；hover 文案准确。
- 从路径节点和交汇节点都能接到兼容锚点、母线、节点或子线；取消和非法目标不留下脏数据。
- 节点增加或减少支路后，角色按物理连接度自动变化，不需要类型转换操作。
- 连接度为 1 的自由节点可作为持续绘线的开路端点；连接度为 0 的孤立节点仍不得进入项目。
- 删除连接度为 2 的节点会局部恢复自动路由；删除连接度大于等于 3 的节点会移除全部邻接线段且不恢复主管。
- 节点碰撞会在一个事务中合并，并清理自环、重复退化线段、悬空边与孤立节点；一次撤销完整恢复。
- 子线真实节点端拖到母线空白位置后立即成为母线节点并连通整条母线；原邻接子线、线路属性和节点选择保持。自动路由无节点穿越仍不连通，多母线交点歧义会阻止提交。
- 节点与图元、母线共同框选或追加多选后，拖动其中任一对象及方向键移动都保持整个混合选区的相对关系；旋转继续绕统一选区中心执行。冲突时整次阻止且只有一条 Toast。
- 点击、删除及批量颜色、方向、主要/辅助级别以相邻持久化节点之间的子线段为单位；共享区间只选中实际经过该区间的边，不扩大为整个网络。
- 保存/刷新、JSON 往返、复制/Duplicate、跨图纸粘贴、网络拆分以及 Worker 重路由后，节点与逻辑线路属性保持确定。
- 单向通行、Source/Target、Switch 门控和监控动画沿统一后的物理拓扑工作，不把节点本身当成业务设备。

## 10. 实现边界

- 本增量不增加节点属性面板、节点命名、节点业务状态、任意角度线路或自由曲线。2026-09-02 的 KD-124 已在独立增量中增加冷却子线端点水流源头；本简报仍不增加目标端属性，也不改变统一节点本身不承担业务设备状态的边界。
- 本增量不改变逻辑线路颜色、标签和单向通行的现有批量属性入口。
- 本增量不解决协同编辑或服务端拓扑合并。
- 自动路由拐角候选节点作为后续增量处理：候选点不持久化，但可直接拖动或起线，并在成功事务中固化为本简报定义的统一节点。具体见 `DERIVED_CORNER_NODE_DESIGN_BRIEF.md`。

## 11. 实现参考

实现交互时继续遵循项目既有的选择手势、简洁文案和画布渐进披露原则：优先复用现有接线、Toast、撤销事务与轻量预览，不增加新的模式切换负担。

## 12. 实现结果

- 统一节点已贯通 Schema、JSON/IndexedDB、撤销/重做、复制、Duplicate、跨图纸粘贴、Worker/主线程路由与网络规范化。
- 子线接入或手动改线会把固化节点展开为相邻节点边；各段继承原颜色、方向和主要/辅助级别，标签只保留一份，并以 `logicalConnectionId` 支持收缩二连路径节点恢复自动布线。节点起线复用同一接线会话；用户显式连接同网络不同节点时可建立闭环，同点自连与重复边仍被拒绝。
- 节点的双击起线在指针层识别第二次快速按下，避免节点拖动使用 pointer capture 后浏览器无法向节点派发原生 `dblclick`；实际双击、单击选择和拖动继续共用既定手势。
- 节点/图元混合变换和子线段拖动提交时均检查实际图元锚点坐标；锚点吸收同坐标自由节点后清理选择中的失效节点，避免退化约束重新参与路由。子线段移动优先吸附相邻路径坐标；提交后根据候选路由识别 `A→B→A` 型立即反向区间，删除对应独占节点并重新路由，有限迭代直至稳定。节点移动预览同时比较连接几何，纯节点拖动不再被“图元和母线均未变化”的快速去重误判为无变化。
- 手动约束冲突按“本次新增无解边”计算，不重复阻止已经无解的线路；几何变化会额外重试全部既有无解网络，解决无解边因没有派生几何而无法进入空间影响走廊、移开遮挡物后仍永久无解的问题。
- 混合选区绕半网格中心旋转时，节点与兼容途径点在旋转后统一吸附 8px 网格；载入器会定向修复旧缺陷生成的节点前缀，使受影响 Schema v25 本地历史恢复可打开，同时保留对其他非法节点的严格校验。
- 监控拓扑按逻辑边展开后的相邻物理区间计算；当目标只经过主管节点一侧时，只生成该有效区间的动画，不误带死端区间。
- 2026-09-01 节点分段与混合移动增量已通过 323 项单元/组件测试（1 项跳过）、23 条无截图端到端流程、主题检查、类型检查和生产构建。回归覆盖旧 `routeNodeIds` 迁移、图元与节点混合移动、节点间边属性/复制/流量，以及分段子线拖回自动路径后的二连节点收缩。按项目约定，节点 hover、拖动手感和复杂冷却管路视觉效果交由用户验收。
- 2026-09-01 持续绘线增量允许连接度为 1 的自由端点和显式闭环；全量 328 项单元/组件测试通过、1 项跳过，25 条无截图端到端流程、主题、类型和生产构建通过。视觉与实际图纸手感继续交由用户验收。
