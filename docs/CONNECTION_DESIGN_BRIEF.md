# 图元接线与中点优先路由设计简报

最后更新：2026-09-04
状态：自动接线、统一节点、节点起线与持续式线路绘制已实现，待用户验收

## 1. 功能摘要

本阶段为 AIDC 运维人员提供冷却与电力一次接线图的拓扑接线能力。用户既可从图元锚点、母线 tap 或节点发起连接，也可显式开启“绘制线路”工具后从画布任意网格点起笔。系统按照端点类型完成校验，并生成避开图元的 8px 正交路径。

同一个图元锚点允许连接多个目标。业务数据保存端点节点和逻辑连接，各逻辑边按最短、少转折和中点优先规则派生路径；同网络线路允许自然重合并形成自动分叉，但已有路径不参与路由评分。派生分叉不保存坐标、不绘制连接点，也不提供任何交互。

## 2. 主要用户动作

1. hover 配置过锚点的图元，显示该图元全部可用于当前图纸的锚点；已接线锚点仍可再次使用。
2. 点击锚点开始接线；网格锚点可从实际位置直接向外或沿边缘两个切向进入线路，非网格锚点只保留进入外部 8px 网格所需的最短正交过渡。
3. 点击兼容图元锚点、合法母线位置、节点或兼容子线完成连接；双击自由节点也可从该节点开始接线。
4. 同一锚点增加第二条及更多连接后，各边分别自动路由；从同一端点出发的自然重合段及分叉位置由显示几何自动生成。
5. 点击独立支路选择对应逻辑连接；点击多条连接共用的主干选择整个网络。删除后按剩余端点关系重新路由。
6. 单选一条独立逻辑子线后，可在右侧属性面板填写或隐藏标签，并拖动标签到源/目标端点及端点附近线段的两侧。
7. 选中线路后渐进显示可拖动线段与途径点；任意普通子线段都可平行拖动，途径点可单独或与图元/母线一起选择、移动、删除和旋转。完整规则见 `MANUAL_ROUTE_WAYPOINT_DESIGN_BRIEF.md`。
8. 点击 HUD 折线按钮进入持续绘制：单击空白点连续新增节点与线段；落到已有拓扑目标或闭环后结束当前线，但工具继续开启；`Esc` 退出。详见 `DIRECT_LINE_DRAWING_DESIGN_BRIEF.md`。

## 3. 交互与画布反馈

- 锚点与线路反馈采用渐进披露：锚点只在图元 hover 或接线期间出现，线路保持常驻低干扰描边。
- 已使用锚点可以继续发起或接收连接；`data-occupied` 只表达拓扑状态，不再禁用交互。
- 接线期间接受类型兼容的图元锚点、母线 tap、节点或子线 8px 显示段；落到子线时创建或复用节点。普通模式下自由节点仍可双击起线；持续绘制工具中可单击起线，并允许用户显式闭合同网络回路。
- 自动分叉没有空心候选、实心节点、拖动手柄或 hover 反馈。
- 普通端点接线中，`Esc` 或鼠标右键仍取消当前临时线。持续绘制工具中，右键只取消当前尚未落段的起笔，`Esc` 保留已确认线段并退出工具。
- 未连接的不同网络正交交叉使用局部拱桥：普通子线穿越电力母线时始终由子线跨越；冷却主要线路与辅助线路交叉时始终由主要线路跨越；其余同级子线交叉继续由后创建线路跨越。拱桥使用真圆弧和对应线路的画布色底衬；可见线与透明命中线共用同一带桥路径。渲染必须同步服从业务层级：母线先于普通子线，冷却辅助组先于主要组，同级组保持稳定创建顺序；监控静态连接按该完整组序逐组重放“拱桥遮罩 → 管体 → 活动/无流量内芯”，不能把同角色内芯合批后一次性盖在全部遮罩之上。

## 4. 类型规则

线路类型共六种：电力、一次回路冷、一次回路热、二次回路冷、二次回路热、通用。

- 电力只能与电力连接。
- 四种专用冷却类型只能连接同类型或通用冷却。
- 通用不能连接电力；通用网络接入首个专用冷却端点后解析为该专用类型。
- 专用网络拒绝接入另一种专用冷却类型；删除最后一个专用端点后恢复通用。
- 同一物理锚点在一个线路网络中只有一个稳定节点，但节点可以连接一到多条逻辑边。
- 已属于不同网络的两个兼容端点完成连接时，系统合并网络并重新解析类型。

## 5. 业务拓扑与当前 Schema v28

- 每张图纸保存若干 `ConnectionNetwork`；网络包含图元锚点节点、母线 tap 节点和端点间逻辑边。
- 每条逻辑边可保存可选六位 HEX `color`，可选 `label`、`labelVisible`、`labelEndpoint` 和 `labelSide`，可选 `monitorDataVisible`、`monitorMetricLabelsVisible` 与最多 5 项 `monitorMetrics`，可选单向通行字段 `flowDirection`，以及冷却子线可选视觉角色 `coolingLineRole`。颜色、标签、运行指标、通行方向和冷却视觉角色均不参与静态路由评分；通行方向约束监控流动拓扑，冷却视觉角色只决定内芯的主要/辅助对比度。
- 子线标签的端点字段使用 `source | target`，侧向字段使用 `negative | positive`。标签绝对坐标不保存；显示时读取当前派生路径端点附近首个非零长度线段，横线对应上/下，竖线对应左/右，并保持 8px 侧向间距。标签同时沿端点线段向子线内侧展开：横向线段按左/右边界对齐并保留 8px 水平 padding，纵向线段按顶/底边界对齐并保留 8px 垂直 padding，文字不越过子线端点。
- 独立边选择回显该边的保存颜色；共享主干的网络选择若包含不同颜色则显示“多种颜色”，不使用任一边的默认色冒充网络当前值。
- 图元节点通过 `elementId + anchorId` 引用稳定资产锚点；母线 tap 通过 `busbarId + offset` 保存拓扑身份。
- 自然共同路径、自动折点和派生分叉仍只是路由几何，不写入 JSON 或 IndexedDB；用户拖动子线、明确把接线落到兼容子线或把节点移动到同点时，才保存网络内自由 `node`。
- Schema v21 以 `ConnectionNode { kind: "node", x, y }` 统一原途径点和 `junction`；Schema v26 进一步把每个持久化节点变为真实边界，相邻节点之间分别保存稳定 `ConnectionEdge`。旧有序 `routeNodeIds` 在载入时展开，自动折点仍不持久化。颜色、单向通行和冷却主要/辅助角色按节点间边配置，原标签只保留在配置端点所在一段；`logicalConnectionId` 仅保留自动布线恢复所需的拆分组关系。
- Schema v27 允许连接度为 1 的自由节点作为可持久化开路端点，并允许显式添加同网络闭环边；同点自连、两节点间重复边和退化自环仍非法。
- v5 及更早项目载入时，保留有效端点和直接端点边，并把经过旧固定分叉连接的端点分量折算为确定性的端点逻辑边；旧分叉的精确坐标不保留。
- 删除图元、母线、逻辑连接或整个网络后，按剩余边和同母线隐式邻接重新拆分连通分量，并重新解析线路类型。

## 6. 中点优先的网络路由

- 网格锚点允许从端点直接向外或沿边缘两个切向开始路由，不要求先沿法向走出固定长度；非网格锚点通过最短正交过渡进入最近的外部 8px 网格，终点反向处理。所有图元端点均禁止向图元内部进入。
- 图元区域是硬障碍。母线占用自身共线网格段；不同线路网络之间继续禁止共线重叠。
- 每个网络独立求解；同一网络内部允许线段自然重合，其他网络与母线仍作为共线占用。后续逻辑边不会因为既有同网络路径而获得长度折扣、复用加分或同分优势。
- 普通子线候选依次比较实际网格长度、完整转折数量和折点到起终点中点的累计距离；母线 tap 继续在其专用候选评分中考虑滑移距离和稳定 offset。该算法是确定性启发式求解，不承诺复杂多终端问题的数学全局最优。
- 同一网络内部自然重合或相交的路径属于同一电气或冷却连通网络，不绘制拱桥；不同网络正交交叉保持拱桥且不改变拓扑。
- 孤立拱桥默认使用 8px 路径跨度和 4px 抬升；靠近端点或相邻拱桥时按可用线段距离收紧。每条线路的全部底衬圆弧合并为一个 path，不为每个交叉新增 DOM，不使用滤镜、阴影或 Mask。
- 图元移动、缩放、旋转，连接增删、母线变化以及项目重载都会重新计算各逻辑边；自然共同段和派生分叉位置随结果更新。
- 没有约束的区间继续使用上述评分；有约束的逻辑边按源端点 → 有序途径点 → 目标端点分段自动求解。共享主干可由多条逻辑边引用同一途径点，但共享点不会改变网络拓扑。

## 7. 选择与删除

- 透明命中描边继续提供稳定点击范围，可见线路不承担命中。
- 点击只有一条逻辑边经过的支路，选择该逻辑边；删除后仅移除该端点关系，并规范化剩余网络。
- 点击两条及以上逻辑边共同经过的主干，选择并高亮整个网络；删除时移除整个网络。
- 冷却逻辑边选中后显示独立 `6px` 中性高亮轨道；纯冷却单选、多选或网络选择可批量设置主要/辅助级别。主要线路使用 `10px / 2px` 管体/内芯、`#262626` 外管和 `50%` 内阴影；辅助线路使用 `4px / 1px`、`#1D1F20` 外管和 `20%` 内阴影，并降低内芯色彩对比度。共享物理区间由主要样式优先。高亮使用最终不透明色，避免多条逻辑边重叠导致亮度累加。
- 派生分叉仍不是业务对象；自由节点可在编辑态 hover 后选择、移动、删除或双击起线。连接度为 1 的节点是开路端点；删除二连节点恢复局部自动路由，删除三连及以上节点移除相关线路。
- 只有恰好单选一条独立逻辑边时才显示标签输入与实例显隐开关，并允许拖动其标签；网络主干、多子线及母线/子线混合选择继续只提供适用于整个选区的颜色与删除操作。

## 8. 母线边界

- 母线仍是独立实体；同一母线全部 tap 隐式连通，不生成沿母线的普通线路边。
- 图元锚点与母线、不同母线间普通子线继续使用端点逻辑边表达。
- 母线 tap 自动滑移、双端 tap 联合求优、缩短时受约束压缩和最短长度规则保持不变。
- “移除普通线路分叉入口”不影响选中母线后从候选 tap 发起普通子线。

## 9. 已确认边界

- 当前实现同锚点多线、网络合并、类型校验、中点优先正交避障、同网络自然重合、拱桥、线路/网络选择删除、撤销重做和旧项目迁移。
- 可选择节点的手动改线、节点起线及兼容子线接入已实现，并部分取代原“不可手动约束折点、普通线路不能作为接线终点”边界；任意中段/自由位置线路标签及服务端协作仍不实现。二连路径节点可删除或通过右侧“恢复自动布线”收缩；三连以上交汇节点删除时移除全部邻接边且不恢复原直连。详细边界见 `MANUAL_ROUTE_WAYPOINT_DESIGN_BRIEF.md` 与 `UNIFIED_CONNECTION_NODE_DESIGN_BRIEF.md`。监控沿节点间业务边和派生显示路径生成独立 WebGL 流动覆盖。
- 视觉检查与验收继续由用户完成；自动化验证聚焦 Schema、拓扑、中点折弯、自然重合网格段、DOM 交互状态、构建和持久化。

## 10. 用户验收重点

- 已经连过线的锚点 hover 后是否仍可再次发起连接。
- 同一锚点连接多个不同位置的目标时，自然共同段和自动分叉位置是否清晰。
- 同长、同转折线路是否把拐点布置在两端中部，并且不因起点侧或目标侧已有主干而偏移。
- 移动任一关联图元后，各线路、中点拐点和自然分叉位置是否自动更新且不穿过图元。
- 从图元四边锚点起线时是否可以在端点立即沿边缘任一切向转弯，同时不进入自身内部或穿过其他图元；母线接入是否仍保持法向。
- 画布是否完全不再出现普通线路分叉候选点或固定连接点。
- 点击独立支路与共同主干时，选择范围及删除结果是否符合预期。
- 独立子线标签在横向端点段的上/下、纵向端点段的左/右是否自然；文字是否沿线段向内侧展开、不越过端点，且水平/垂直方向的 8px padding 是否合适；拖动切换端点后，重路由、隐藏/恢复和撤销/重做是否保留预期方位。
- 不同网络的交叉拱桥、六种类型颜色、母线 tap 与普通子线是否保持原有语义。

## 12. 2026-09-02 电力子图外部供电入口

- Schema v31 为 `ConnectionEdge` 增加可选 `externalSupplyEndpoint: "source" | "target"`，只允许出现在电力子图的子线上，分别把逻辑边的物理起点端或终点端标记为外部供电入口。顶层电力图、冷却图和母线不提供该字段。
- 编辑模式单选或纯子线多选时，右侧“外部供电入口”支持不作为入口、起点端、终点端和批量混合值。入口只声明父级电源从哪一端进入，不隐式修改 `flowDirection`；两者冲突时显示提示并按真实方向约束停流。
- 父图关联设备带电且子图至少配置一个显式入口时，监控拓扑只把这些入口端合并成一个多节点外部供电边界，停用母线端点和单向自由边界的自动 Source 推断。没有显式入口的 v1–v30 项目继续使用原兼容规则；父图失电时显式入口也不产生电流。
- 节点分割只让仍接触物理入口端的第一段或最后一段继承标记；边反转同步翻转端点；删除二连节点合边时只保留仍位于合并后外端点的入口。复制、批量设置、撤销/重做、保存和 JSON 往返保留配置。
