# 图元运行指标与告警设计简报

状态：待用户确认  
最后更新：2026-08-19

## 1. 功能摘要

为 AIDC 运维人员在监控模式中提供紧贴图元的实例级运行指标，使其无需离开一次接线图即可读取关键模拟数值和三级告警状态。首版只使用项目内模拟数据，不接入实时遥测；每个普通图元最多配置 5 项指标，配置属于图元实例而不是图元资产模板。

## 2. 首要用户任务

运维人员应能在监控画布上快速把“设备身份、当前数值、是否越过告警阈值”作为同一个信息组读完，并立即通过数值颜色区分次要、重要和紧急告警。

## 3. 设计方向

- 延续“中性、克制、精密”的深色运行台风格，画布与拓扑仍是第一视觉层级。
- 设备名称与运行指标组成一个无卡片背景的标签组，复用既有世界空间文字、画布色描边和标签方位，不新增浮动仪表卡或监控弹窗。
- 色彩只作用于指标数值：正常为中性色，次要为黄色，重要为橙色，紧急为红色；指标名称、单位和设备名称保持中性。
- 视觉上不显示“次要 / 重要 / 紧急”文字或告警图标；辅助技术可通过隐藏语义读取当前告警等级。

## 4. 布局策略

### 编辑模式右侧属性面板

- 仅恰好单选一个普通图元时显示“运行数据”区。
- 保留现有“显示设备标识”实例开关，新增独立的“显示运行数据”实例开关。
- 最多添加 5 项指标；达到上限后禁用添加入口并显示 `最多 5 项`。
- 每项指标按紧凑纵向结构编辑：指标名称、单位、数值精度、模拟最小值/最大值、阈值模式和三级阈值。
- 指标顺序即监控标签中的显示顺序；首版提供添加、删除和上移/下移，不引入拖拽排序。

### 画布组合标签

- 组合标签与既有设备标识共用同一个 `labelPlacement` 方位与自动避让结果。
- 两个开关均开启：第一行显示设备名称，后续最多 5 行显示运行指标。
- 仅名称开启：保持现有单行设备标识。
- 仅运行数据开启：指标从组合标签第一行开始，不保留空名称行。
- 两者均关闭：不创建组合标签布局或命中区域。
- 图元旋转不旋转标签组，也不改变其画布侧向；编辑模式拖动设备名称改变的方位同时决定监控指标位置。
- 每个指标行使用 `指标名称  数值单位`，名称靠近图元一侧，数值与单位形成稳定的右侧读数列。

## 5. 关键状态

| 状态 | 行为 |
| --- | --- |
| 未配置指标 | 监控模式只按“显示设备标识”决定是否显示名称，不显示空指标占位 |
| 已配置但关闭运行数据 | 保留配置和阈值，画布不显示指标 |
| 正常 | 数值使用中性文字色 |
| 次要告警 | 仅数值使用统一黄色 |
| 重要告警 | 仅数值使用统一橙色 |
| 紧急告警 | 仅数值使用统一红色 |
| 同时命中多级规则 | 按紧急 > 重要 > 次要取最高等级 |
| 阈值无效 | 编辑区就地指出顺序错误并拒绝提交该项无效配置，保留上一个合法值 |
| 达到 5 项 | 禁止继续添加，不影响已有指标编辑与删除 |
| 图元位于视口外 | 沿用现有 SVG overscan 裁剪，不挂载其组合标签 |

## 6. 交互模型

1. 用户在编辑模式单选图元，在右侧“运行数据”中开启显示并添加指标。
2. 用户填写名称、单位、精度、模拟范围，选择阈值模式并填写三级阈值。
3. 字段继续使用现有属性面板事务：输入期间为草稿，失焦或 Enter 提交，Escape 恢复已保存值；每次合法提交进入图纸撤销/重做历史。
4. 进入监控模式后立即为每项指标生成首个模拟值，随后由单一全局节拍每 30 秒更新一次。
5. 每次更新后按该指标的阈值计算最高告警级别，只更新运行态数值与组合标签中的数值颜色。
6. 监控模式保持只读；切换图纸、缩放、平移和下钻不会修改指标配置。

## 7. 内容与数据要求

### 单项配置

- 稳定 ID：实例内唯一，用于运行态绑定。
- 指标名称：必填，例如“出水温度”。
- 单位：可选，例如 `°C`、`kW`、`bar`。
- 精度：首版支持 0、1、2 位小数，默认 1 位。
- 模拟范围：必填最小值和最大值，且最小值小于最大值。
- 阈值模式：上限告警、下限告警、正常区间外告警。
- 三级阈值：次要、重要、紧急。

### 阈值约束

- 上限告警：`次要 < 重要 < 紧急`；数值达到对应阈值后告警。
- 下限告警：`紧急 < 重要 < 次要`；数值低于或等于对应阈值后告警。
- 正常区间外告警：配置三级下界和上界，满足 `紧急下界 < 重要下界 < 次要下界 < 次要上界 < 重要上界 < 紧急上界`；数值越远离正常区间，等级越高。

### 模拟与持久化

- 模拟器采用简单的离散更新，不做帧间插值、趋势拟合或物理计算。
- 首值在进入监控模式时生成，之后每 30 秒生成一个位于配置范围内的新数值。
- 全图复用一个 30 秒节拍，不为每个图元或指标创建独立定时器。
- 指标配置、显隐和顺序属于 `DiagramElement` 实例，进入项目 Schema、JSON、IndexedDB、dirty 状态和编辑历史；不写入 `AssetDefinition` 或 SVG。
- 当前模拟数值和派生告警等级属于高频运行态，不进入项目 JSON、编辑历史或 dirty 状态。
- 复制、Duplicate 和跨图纸复制图元时复制指标配置与阈值，但新实例获得新的指标 ID，并独立生成模拟值，不复制源实例当前数值。
