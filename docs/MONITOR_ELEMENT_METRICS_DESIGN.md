# 图元与子线标签运行指标、告警设计简报

状态：已实施，待用户验收
最后更新：2026-09-03

## 1. 功能摘要

为 AIDC 运维人员提供紧贴图元或子线标签的实例级运行指标：指标可配置为数值型或文本型，编辑模式使用稳定预览值检查组合标签布局，监控模式读取每 30 秒更新的模拟值和三级告警状态。首版只使用项目内模拟数据，不接入实时遥测；每个普通图元或节点间子线最多配置 5 项指标，配置属于具体实例而不是图元资产模板或线路类型。

## 2. 首要用户任务

运维人员应能在监控画布上快速把“设备身份、当前读数或状态、是否告警”作为同一个信息组读完，并立即通过异常数据自身的背景色区分次要、重要和紧急告警。

## 3. 设计方向

- 延续“中性、克制、精密”的深色运行台风格，画布与拓扑仍是第一视觉层级。
- 设备名称与运行指标组成一个无整体卡片背景的标签组，复用既有世界空间文字、画布色描边和标签方位，不新增浮动仪表卡或监控弹窗；只有异常数值或文本状态自身具有状态底色。
- 指标名称与单位始终保持原中性样式和透明背景；正常数值或文本状态也保持透明并沿用中性色。次要、重要、紧急数据分别使用黄色、橙色、红色紧凑背景，数据文字统一为黑色。设备名称始终保持中性。
- 视觉上不显示“次要 / 重要 / 紧急”文字或告警图标；辅助技术可通过隐藏语义读取当前告警等级。

## 4. 布局策略

### 编辑模式右侧属性面板

- 仅恰好单选一个普通图元或一条节点间子线时显示“运行数据”区；共享主干和多条子线不显示批量指标入口。
- 图元使用“显示图元标签”，子线使用“显示子线标签”；两者均与“显示运行数据”和默认开启的“显示指标名称与单位”总开关相互独立。名称/单位开关统一作用于当前实例全部指标，不提供逐指标显隐。
- 最多添加 5 项指标；达到上限后禁用添加入口并显示 `最多 5 项`。
- 每项指标先配置指标名称和数据类型。数值型继续配置单位、数值精度、模拟最小值/最大值、阈值模式和三级阈值；文本型配置至少一个“候选状态 + 状态等级”，默认提供“运行 / 停机 / 离线”。
- 指标顺序即两种模式组合标签中的显示顺序；首版提供添加、删除和上移/下移，不引入拖拽排序。
- 开启“显示运行数据”后，编辑画布立即显示组合标签预览；数值型固定取模拟范围中间值，文本型固定取首个正常候选状态（没有正常项时取首项），配置变化时重新计算，但不随时间刷新。

### 画布组合标签

- 组合标签与既有设备标识共用同一个 `labelPlacement` 方位与自动避让结果。
- 设备名称、运行数据及指标名称与单位均开启：第一行显示设备名称，后续最多 5 行按“名称(单位) + 读数”或“名称 + 状态”显示运行指标。
- 仅名称开启：保持现有单行设备标识。
- 仅运行数据开启：指标从组合标签第一行开始，不保留空名称行。
- 运行数据开启但指标名称与单位关闭：最多 5 行只显示读数或文本状态，一个开关统一作用于全部指标；异常数据背景继续生效，自身尺寸不变，只随仅值标签重新对齐。
- 设备名称与运行数据均关闭：不创建组合标签布局或命中区域。
- 图元旋转不旋转标签组，也不改变其画布侧向；编辑模式拖动设备名称改变的方位同时决定监控指标位置。
- 数值型指标行使用 `指标名称(单位)  数值`，单位非空时以无空格半角括号紧跟名称，例如 `有功功率(kW)`；名称与单位靠近图元一侧，右侧读数列只显示当前数值。文本型使用 `指标名称  状态`，不显示单位。多条指标分别计算名称列和数据列：数据列只取全部当前数值/文本状态中的最大宽度，所有行共享该宽度并统一右对齐，异常背景也使用完整数据列宽；设备标识、子线标题、指标名称和单位均不参与数据列宽计算。名称列与数据列之间的布局间距为 `0px`。

## 5. 关键状态

| 状态 | 行为 |
| --- | --- |
| 未配置指标 | 两种模式均只按“显示设备标识”决定是否显示名称，不显示空指标占位 |
| 已配置但关闭运行数据 | 保留配置和阈值，画布不显示指标 |
| 已配置且关闭指标名称与单位 | 全部指标行只显示当前读数或文本状态，保留异常数据背景和辅助技术语义；徽标自身尺寸不变，只随仅值标签重新对齐 |
| 编辑模式预览 | 数值型使用范围中间值并按精度格式化；文本型使用首个正常候选或首项；只在配置变化时重新计算，不启动 30 秒定时器 |
| 正常 | 标题、单位与数据均保持透明，使用既有中性文字色 |
| 次要告警 | 标题与单位保持原样且无底色；只有数据使用统一黄色背景和黑色文字 |
| 重要告警 | 标题与单位保持原样且无底色；只有数据使用统一橙色背景和黑色文字 |
| 紧急告警 | 标题与单位保持原样且无底色；只有数据使用统一红色背景和黑色文字 |
| 同时命中多级规则 | 按紧急 > 重要 > 次要取最高等级 |
| 阈值无效 | 编辑区就地指出顺序错误并拒绝提交该项无效配置，保留上一个合法值 |
| 达到 5 项 | 禁止继续添加，不影响已有指标编辑与删除 |
| 图元位于视口外 | 沿用现有 SVG overscan 裁剪，不挂载其组合标签 |

## 6. 交互模型

1. 用户在编辑模式单选图元，在右侧“运行数据”中开启显示并添加指标。
2. 用户填写名称并选择数值或文本类型：数值型填写单位、精度、模拟范围和三级阈值；文本型增删候选状态并为每项指定正常、次要、重要或紧急等级。
3. 字段继续使用现有属性面板事务：输入期间为草稿，失焦或 Enter 提交，Escape 恢复已保存值；每次合法提交进入图纸撤销/重做历史。
4. 编辑画布立即以稳定值预览组合标签；修改配置或任一显隐开关后同步更新预览。指标名称与单位总开关关闭时，全部指标只保留读数或文本状态；时间经过不会改变预览值。
5. 进入监控模式后立即为每项指标生成首个模拟值，随后由单一全局节拍每 30 秒更新一次。文本型按正常 90、次要 6、重要 3、紧急 1 的等级权重抽样；未配置的等级不参与并自动归一化，同等级多个候选平分该等级权重。
6. 数值型按当前数值与阈值计算最高告警级别，文本型直接使用候选状态配置的等级；两种类型都只更新派生值，以及组合标签中的数据背景与数据文字颜色，标题和单位样式不变。
7. 监控模式保持只读；切换图纸、缩放、平移和下钻不会修改指标配置。

## 7. 内容与数据要求

### 单项配置

- 稳定 ID：实例内唯一，用于运行态绑定。
- 指标名称：必填，例如“出水温度”。
- 数据类型：数值或文本。
- 数值型：单位可选，例如 `°C`、`kW`、`bar`；精度支持 0、1、2 位小数；模拟范围满足最小值小于最大值；阈值模式为上限、下限或正常区间外告警，并配置次要、重要、紧急三级阈值。
- 文本型：至少一个候选状态，每项包含稳定 ID、1–24 字符的状态文本和正常/次要/重要/紧急等级；不配置单位、精度、范围或数值阈值。

### 阈值约束

- 上限告警：`次要 < 重要 < 紧急`；数值达到对应阈值后告警。
- 下限告警：`紧急 < 重要 < 次要`；数值低于或等于对应阈值后告警。
- 正常区间外告警：配置三级下界和上界，满足 `紧急下界 < 重要下界 < 次要下界 < 次要上界 < 重要上界 < 紧急上界`；数值越远离正常区间，等级越高。

### 模拟与持久化

- 模拟器采用简单的离散更新，不做帧间插值、趋势拟合或物理计算。
- 编辑模式数值预览固定为模拟范围中间值并按精度舍入，文本预览固定为首个正常候选或首项；不创建刷新定时器。
- 监控首值在进入监控模式时生成，之后每 30 秒刷新：数值型在配置范围内均匀取样；文本型按 `90 / 6 / 3 / 1` 的等级权重取样，使绝大多数模拟状态保持正常，次要与重要低频出现，紧急最少。
- 全图复用一个 30 秒节拍，不为每个图元、子线或指标创建独立定时器。
- 指标配置、运行数据显隐、全部指标名称与单位显隐及顺序属于 `DiagramElement` 或 `ConnectionEdge` 实例，进入项目 Schema、JSON、IndexedDB、dirty 状态和编辑历史；不写入 `AssetDefinition`、线路类型或 SVG。
- 当前模拟数值和派生告警等级属于高频运行态，不进入项目 JSON、编辑历史或 dirty 状态。
- 复制、Duplicate 和跨图纸复制图元时复制指标类型、数值阈值或文本候选配置，但新实例获得新的指标 ID，并独立生成模拟值，不复制源实例当前值。

## 9. 实施结果

- 项目 Schema 已升级至 v18；v1–v17 项目继续迁移，旧指标自动识别为数值型，旧项目默认显示指标名称与单位；运行指标配置、三类显隐状态与顺序可通过 JSON、IndexedDB、历史和复制链路持久化。
- 编辑模式右侧属性面板已提供设备名称、运行数据整体及全部指标名称与单位三个独立显隐开关，以及最多 5 项指标的添加、删除和排序；指标可切换数值/文本类型，并分别编辑数值阈值或文本候选状态等级。
- 编辑模式已接入中间数值或正常文本状态的稳定预览；监控模式已接入立即生成与 30 秒统一刷新，文本状态使用正常优先的等级加权抽样。预览值、运行值和告警只存在于派生运行态，不修改项目 dirty 或历史。
- 画布组合标签已实现设备名称、运行数据整体及指标名称与单位独立显隐和统一四侧避让；隐藏指标名称与单位时不挂载相应文字并按可见值收紧宽度。2026-08-29 起，指标名称与单位始终保持原中性样式和透明背景；三级异常只给数值或文本状态增加黄、橙、红紧凑背景与黑色文字。隐藏名称与单位时异常数据徽标自身尺寸不变，只随仅值标签重新对齐。
- 2026-08-31 将多指标统一名称列与数值列的基准间距由 `8px` 收紧为 `0px`；2026-09-03 进一步把两列改为独立测量，数据列只由最长当前数据决定，所有数据行及异常背景共享该列宽。超长设备标识、子线标题或指标名称只扩展对应名称/整体区域，不再改变数据列宽；图元数据块在右侧起始对齐、左侧结束对齐、上/下侧居中，子线继续按端点方向起始/结束对齐，因此长标题不会把数据块推离既有方位基准。未修改字号、行高、数据模型或持久化。
- 复制、粘贴、Duplicate 与跨图纸复制保留配置并重建指标 ID，不复制当前模拟值。
- 201 项单元/组件测试通过、1 项跳过，类型检查、主题检查、生产构建和 13 条无截图端到端流程通过；其中已断言一个开关同时隐藏多项指标名称与单位、数值和文本状态在编辑及监控模式继续显示，最终布局与颜色观感由用户验收。
- 2026-08-29 异常背景增量新增数据徽标边界与标题显隐后徽标尺寸稳定单测，以及正常数据无背景、异常数据背景等级匹配、标题不变和数据黑字的无截图 DOM 断言；同时把告警等级纳入标签缓存判等，保证文字不变但等级变化时立即刷新底色。全量 294 项单元/组件测试通过、1 项跳过，类型、主题、生产构建与 1 条定向端到端流程通过。颜色、相邻异常数据及不同缩放观感继续由用户验收。
- 2026-09-01 子线标签扩展将项目升级至 Schema v28：恰好单选一条节点间子线时复用同一指标编辑器、稳定预览、30 秒模拟节拍与告警样式；名称、运行数据及指标标题三个开关相互独立。配置保存在 `ConnectionEdge`，节点拆分时整组显示数据只跟随标签端点段，二连节点收缩继续保留，复制线路时重建指标 ID。v1–v27 项目缺省保持子线名称可见、运行数据隐藏和指标标题可见。

## 11. 已确认的模拟改造

KD-133 已完成第一阶段实现，不再把本文件第 6–7 节的“每项指标独立、全范围均匀取样或按固定文本权重抽样”作为标准演示行为。旧机制仅由显式使用 `MockMonitorMetricDataProvider` 的兼容入口或未知自定义指标回退使用。

标准演示现由版本化设备档案、稳定指标语义和统一 `MonitorMetricRuntimeSnapshot` 生成最终读数与严重度；同一设备的功率、温度、压力、流量、泵阀状态和链路动画按简化运行约束联动。历史手工模拟范围和阈值不删除、不自动改写，但不再主导已识别设备的标准演示异常。设备默认范围、页面异常预算、运行时补充指标、单位归一和 RuntimeBundle v2 迁移详见 `DEMO_RUNTIME_SIMULATION_DESIGN.md`。
