# 图元锚点编辑器设计简报

- 状态：已实现，待用户视觉与操作验收
- 日期：2026-08-13
- 范围：图元资产级接线锚点定义；不包含线路绘制、自动路由和线路管理

## 1. 功能摘要

图元锚点编辑器面向 AIDC 一次接线图的图元维护人员，用于在 SVG 图元资产上定义后续线路连接所需的稳定端点。锚点属于图元资产模板，同一 `assetKey` 的所有画布实例自动继承；SVG 文件本身不被修改。

## 2. 主要用户动作

用户选择一个图元，在其原始尺寸边界上的合法 8px 网格点添加锚点，并确认名称与类型。出线方向由锚点所在边缘自动确定且不可修改；完成后把锚点定义应用到项目资产，供当前及未来图元实例使用。

## 3. 设计方向

沿用项目“中性、克制、精密”的深色运行台语言。图元及其边缘网格是唯一视觉焦点；外壳不使用装饰卡片，锚点颜色只表达接线类型，选中状态同时使用轮廓与明度，避免只依赖颜色。

## 4. 布局策略

- 图元素材卡片在 hover 或键盘 focus-within 时，于右上角显示单一编辑图标按钮；默认状态不占用素材图元的视觉中心。
- 点击编辑图标打开大型图元编辑弹窗。弹窗采用双栏：左侧图元列表，右侧图元编辑区；不增加独立第三栏。
- 弹窗左侧复用现有图元素材的分类、搜索、缩略图和名称展示组件；在弹窗模式中单击用于切换当前图元，不启用拖放或双击插入。
- 弹窗右侧以 8px 点阵画布为主体：SVG 按原始宽高放置并显示明确边界，边缘合法网格点承担添加反馈。
- 右侧编辑区顶部使用与一次接线图界面一致的紧凑工具栏：当前图元名称与锚点数量作为上下文信息；撤销、重做、删除和适配视口均使用图标按钮。
- 锚点名称使用单行输入框，类型使用下拉选择器，均放在顶部工具栏。未选中锚点时名称、类型和删除控件禁用，不新增底部属性条或第三栏。
- 弹窗不设置底部操作区；右上角仅保留关闭图标按钮。所有合法修改即时应用到当前项目，无需额外确认。

## 5. 数据模型

`AssetDefinition` 增加 `anchors[]`，不把锚点重复写入 `DiagramElement`：

```ts
type AnchorType =
  | 'electrical'
  | 'cooling-primary-cold'
  | 'cooling-primary-hot'
  | 'cooling-secondary-cold'
  | 'cooling-secondary-hot'
  | 'cooling-general'

type AnchorDirection = 'top' | 'right' | 'bottom' | 'left'

interface SymbolAnchor {
  id: string             // 自动生成、资产内唯一、不可编辑
  name: string           // 可编辑，默认按类型顺序生成
  x: number              // SVG 原始坐标，8px 整数倍
  y: number              // SVG 原始坐标，8px 整数倍
  direction: AnchorDirection
  type: AnchorType
}
```

默认名称为“电路 1”“一次回路冷 1”等；修改类型后，只有仍使用自动名称时才同步重编号，用户手动名称不被覆盖。

合法位置必须同时满足：

1. `x`、`y` 都是 8 的整数倍。
2. 点位位于原始图元矩形的一条边上。
3. 点位不是四个角。
4. 同一资产的同一坐标最多存在一个锚点。

方向由边缘唯一推导：上边向上、右边向右、下边向下、左边向左。方向作为系统派生字段保存在数据中，但界面不提供方向控件且用户不可修改；锚点移动后必须根据新位置所在边缘自动更新方向，校验时方向必须与坐标对应的边缘一致。

项目 JSON 模式版本升级并提供旧版本迁移：旧项目导入时为每个资产补 `anchors: []`；导出、IndexedDB 保存和重新打开必须保留全部锚点。SVG 源文件不写入元数据。

## 6. 交互模型

### 进入与退出

- hover 图元素材卡片时，右上角出现编辑图标；按钮必须有“编辑 {图元名称} 锚点”的无障碍名称和悬停提示。
- 点击编辑图标只打开弹窗，不触发素材拖动、双击插入或卡片按压状态；按钮的 pointer 与 click 事件需要阻止冒泡。
- 弹窗打开后自动选中触发入口对应的图元；左侧列表可继续切换其他图元。
- 添加、移动、删除、名称和类型修改均即时写入当前项目状态、进入撤销历史并产生项目 dirty 状态；不维护等待应用的弹窗工作副本。
- 左侧切换图元不会触发保存或确认提示，已完成的修改保持生效。
- 点击弹窗右上角关闭图标直接退出编辑器，不回滚已完成修改；`Escape` 提供等效键盘关闭能力。关闭后焦点返回触发弹窗的编辑按钮。

### 添加

- 指针移动到合法边缘网格点时显示添加预览及推导出的外向方向。
- 单击合法点添加锚点并立即选中；自动生成稳定 ID、名称和默认方向。
- 单击角点、非边缘网格点或已有锚点位置不创建数据，并给出简短原因。
- 新增锚点默认类型：电力分类资产使用“电路”；冷却分类资产使用“通用”，用户可在六种类型中修改。

### 编辑

- 单击锚点或右侧列表项进行选择，画布和列表保持同步。
- 锚点可沿图元边缘拖动，预览只落在合法 8px 网格点；不能穿过角点连续转向，需要结束当前拖动后再次移动。
- 顶部工具栏可通过输入框修改名称、通过下拉选择器修改类型；不显示可编辑方向字段，坐标也不提供手工输入，避免绕过画布约束。
- `Delete/Backspace` 或顶部删除图标移除当前锚点；添加、移动、删除、名称和类型修改均支持顶部图标或快捷键撤销/重做。

### 图元实例变换

- 画布实例从资产 `anchors[]` 读取锚点，并以图元原始尺寸计算相对比例。
- 图元缩放时锚点等比跟随，允许缩放后的实际端点不落主画布 8px 网格。
- 图元旋转时锚点位置和出线方向同步旋转；未来线路从变换后的真实端点出发，再进入正交网格路由。

## 7. 关键状态

- 无锚点：显示“在图元边缘的网格点单击添加锚点”，不制造空白卡片。
- 悬停合法点：显示添加预览和默认方向。
- 悬停角点：显示禁止反馈与“角点不能添加锚点”。
- 悬停非边缘点：不高亮为可添加；点击后提示“锚点只能位于图元边缘”。
- 重复位置：保留原锚点选中反馈，提示“该位置已有锚点”。
- 已选择：画布锚点与顶部名称输入框、类型下拉和删除图标同步；类型不能只靠颜色表达。
- 素材卡片入口：鼠标 hover 与键盘 focus-within 都显示编辑按钮；触屏/无 hover 环境可通过聚焦卡片后访问按钮。
- 弹窗打开：焦点进入弹窗标题或首个可操作控件；焦点限制在弹窗内，关闭后返回触发编辑按钮。
- 即时应用：每次合法操作立即反映到当前项目并更新撤销/重做状态；关闭弹窗不出现应用、放弃或未保存确认。
- 旧项目迁移：无锚点资产以空数组加载，不阻塞项目打开。
- 数据异常：导入时拒绝非8px坐标、角点、非边缘点、重复ID或重复坐标，且不得覆盖当前项目。

## 8. 内容要求

- 类型名称：电路、一次回路冷、一次回路热、二次回路冷、二次回路热、通用。
- 核心提示：锚点只能添加在图元边缘的8px网格点，四个角不可用。
- 错误提示必须说明具体原因，不使用“操作失败”一类泛化文案。

## 9. 验收标准

- 每个图元资产可拥有0个或多个锚点，所有实例按 `assetKey` 自动继承。
- 添加和拖动只能落在非角点的边缘8px网格点；重复坐标被拒绝。
- 默认名称、默认类型和外向方向符合规则；名称与类型可编辑，方向由边缘自动确定且不可编辑。
- 添加、移动、删除及名称/类型修改即时应用并支持撤销/重做；弹窗无取消、应用按钮，关闭不回滚修改。
- 素材 hover 编辑按钮不干扰拖入和双击插入；打开弹窗后默认选中触发图元，左侧列表可切换全部图元。
- 弹窗保持双栏结构，右侧画布是主要面积；名称输入框、类型下拉以及撤销、重做、删除图标均收纳于画布顶部工具栏，不形成底部属性条或第三栏。
- JSON导出导入、IndexedDB保存打开和旧版本迁移不丢失或制造非法锚点。
- 图元缩放、旋转后的锚点位置和方向计算正确，不强制重新吸附主画布网格。
- 自动化覆盖四边、四角、重复点、六种类型、迁移、JSON往返和实例几何变换；视觉观感由用户验收。
