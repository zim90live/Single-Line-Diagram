# 第一阶段编辑系统方案

- 状态：AIDC 基线重构已实现，待用户验收
- 日期：2026-08-13
- 范围：第一阶段产品、交互、数据、技术方案与验收基线

## 1. 用户与范围

主要用户是 AIDC 运维人员，通过桌面 Web 系统维护冷却、电力两套线路的多层级图纸。每套线路包含园区、楼宇、POD、设备等层级，并通过下钻、返回和面包屑关联。

第一阶段先完成图元排布与项目交换，当前增量增加资产级接线锚点定义和指定图元实例颜色；仍不实现线路连接、拓扑管理和监控。当前素材库登记 `src/assets/symbols/` 中的 22 个 SVG 文件并呈现为 21 个逻辑图元，Switch On/Off 归为一个 Switch，Cabinet A/B 为两个独立图元；原有示例图元已从活动目录移除。

## 2. 工作区与交互

- 顶部：项目名称、保存状态、新建、打开、保存、JSON 导入与导出。
- 次级工具栏：返回、当前线路、图纸路径、撤销/重做、复制/粘贴/删除、缩放。
- 左侧：冷却/电力图纸树与素材库；所有树行保持单行。
- 中央：顶部/左侧标尺、WebGL 自适应单级点阵网格和 SVG 编辑覆盖层。
- 右侧：单选图元属性；多选时显示批量状态和删除动作。
- 滚轮按指针位置缩放；鼠标中键平移；左键单选、组合键多选、空白拖动严格框选。
- 多选时每个图元保留独立选中轮廓，外层显示整体轴向包围框和缩放/旋转手柄。缩放保持各图元比例和相对位置；旋转绕选区中心按 90° 步进进行；提交结果统一贴合 8px 网格。
- 从素材区拖入时立即显示图元尺寸的十字对齐带；画布内拖动则只在图元产生实际 8px 网格位移后显示。多选拖动时每个图元都产生一组十字带，将所有带先合并为单一 SVG 裁剪区再着色，重叠部分不叠加透明度。
- 画布以 8px 世界单位为最小网格并以单一样式点阵呈现，所有点使用相同大小和颜色；缩小时从 8、16、24、32px 等 8px 倍数中选择当前可见间隔，使屏幕点距不低于 8px。标尺直接使用相同间隔，文字标签只按可见点的整数倍降低密度；网格原点锁定世界坐标。图元按 SVG 原始宽高插入，SVG 本体不附加名称或背景；后续 KD-045 在图元旁增加独立的设备标识文字，不改变 SVG 和图元几何。
- 2WV、CV、Generator、Grid、MP、Transformer 的单个实例可在右侧属性面板修改单一颜色或恢复默认；Switch 在后续 Schema v13 增量中改为分别配置关/开颜色，并可从编辑属性面板控制独立运行态。画布保留 SVG 透明轮廓，不修改素材文件。
- 缩放保持原始宽高比，并按宽高同时贴合 8px 网格的最小合法比例离散变化；旋转按 90° 步进。
- 一个连续移动、缩放或旋转手势只产生一个历史事务；预览不写项目文档，提交时同步写入。

## 3. 项目文档

项目使用独立、带版本号的 JSON 业务格式，不保存 Three.js/R3F 或 SVG DOM 临时对象：

```text
ProjectDocument
├── schemaVersion
├── project
├── lineSystems[]        # cooling / power
├── diagrams[]           # 父子层级、网格、持久化 viewport
├── elements[]           # assetKey、位置、尺寸、旋转、名称、属性
├── assets[]             # 素材索引
└── extensions           # 后续端口、连线和监控映射
```

- Zod 校验版本、结构及图纸/素材引用完整性；失败导入不替换当前项目。
- Dexie/IndexedDB 保存浏览器本地项目；单个 JSON 用于备份和跨机器交换。
- 打开已保存项目保持“已保存”，导入文件标记为待保存；画布 viewport 与图元一起持久化。
- 存储通过 Repository 隔离，未来接入服务端时不改变编辑器和文档模型。

## 4. 技术栈

| 层次 | 选择 | 职责 |
| --- | --- | --- |
| 应用 | React 19 + TypeScript 7 + Vite 8 | 桌面工作区、业务组件和工程构建 |
| 画布底层 | Three.js + React Three Fiber | 正交 WebGL 网格；为后续监控动画和批量绘制预留能力 |
| 编辑覆盖层 | 原生 SVG + 自定义几何/指针投影 | 图元、标尺、选择、框选、变换手柄和后续端口/线路 |
| 交互事务 | 项目内自定义历史 | begin → preview → commit/cancel，单手势单事务 |
| UI 系统 | AIDC typed Token / Recipe + React 原语 + Lucide | 确定性主题 CSS、控件一致性和业务层自由组装 |
| 状态/数据 | Zustand + Zod | 项目状态、选择状态、版本化 JSON 与引用校验 |
| 本地存储 | Dexie + IndexedDB | 本地保存、打开和可替换 Repository 边界 |
| 验证 | Vitest + Testing Library + Playwright | 类型、领域、存储、DOM 和真实浏览器交互；不做截图验收 |

## 5. 模块边界

```text
project-domain      版本化项目、线路、图纸、图元与 viewport
editor-geometry     坐标投影、缩放中心、网格吸附、旋转框选
editor-webgl        GLSL 自适应单级点阵和未来高频运行态图层
editor-svg          图元、选择、框选、变换与命令历史
design-system       typed Token / Recipe、生成 CSS 和 UI 原语
hierarchy-nav       单行图纸树、下钻、返回和面包屑
symbol-library      素材注册、搜索、拖入和 assetKey 解析
properties-panel    单选属性草稿与提交、多选状态
project-storage     IndexedDB Repository、导入、导出和校验
```

编辑文档与后续监控运行态必须分层：遥测模拟、告警和动画不进入编辑历史或项目 JSON，通过统一数据源适配接口覆盖在持久图纸之上。
