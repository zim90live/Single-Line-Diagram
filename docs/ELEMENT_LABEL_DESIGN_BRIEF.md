# 图元设备标识标签设计简报

最后更新：2026-08-17

## 目标

每个普通图元默认在旁侧显示右侧属性面板中的“设备标识”，帮助运维人员在密集的一次接线图中稳定识别设备；用户也可单独隐藏任一图元的标签。标签是图元的附属显示信息，不改变图元本身的几何和线路拓扑。

## 内容与呈现

- 标签内容读取 `DiagramElement.properties.tag`，不使用图元“名称”字段。
- 新插入图元自动生成同图纸内可辨识的默认标识，例如 `CHWP-01`；用户仍通过右侧属性面板修改。
- 标签使用单行水平文字、无卡片和背景，随画布一起缩放；缩小时允许因字号过小而看不清，不切换为屏幕固定尺寸。
- 使用紧凑的 10px 世界字号和画布色细描边保证线路经过附近时仍可辨识。标签不计入图元尺寸、框选、对齐、吸附、缩放包围框或线路障碍，其排布不受主画布 8px 网格约束。

## 自动排布

- 系统在画布坐标的下、右、上、左四侧生成候选，默认视觉间距为 2px；沿边避让使用独立的 2px 精细步进。
- 自动排布优先避开本图元锚点及其向外的初始出线走廊，并尽量避免覆盖其他图元和已经排布的标签；评分相同时保持稳定候选顺序，避免无原因跳动。
- 用户指定某一侧后，系统只在该侧沿边缘方向按 2px 精细步进寻找更合适的位置；持久化的是侧向，不保存容易失效的绝对文字坐标。
- 图元旋转时，标签文字保持水平，已选侧向保持画布坐标语义不变；系统只重新计算该侧的具体位置和锚点避让。

## 交互

- 单选一个普通图元后，右侧属性面板在“设备标识”字段下提供“显示图元标签”开关，并注明“仅控制当前图元”；多选或未选中时不提供批量显隐入口。
- 关闭后不生成该图元的标签布局或命中区域，并清除其标签交互选中态；再次打开后按既有自动或人工侧向重新计算位置。其他图元和母线标签不受影响。
- 标签默认不响应指针，首次点击仍选择图元。
- 只有当前恰好单选一个普通图元，且没有母线或线路选择时，该图元标签才允许点击和拖动。
- 拖动过程中根据指针相对图元中心的主方向切换到上、右、下或左侧；系统实时计算该侧具体位置，松手后作为一个历史事务提交。
- 多选图元不能选中或拖动标签；不增加双击和原位编辑。设备标识内容继续使用现有右侧属性面板输入框修改。
- `Esc` 清除对象选择时同步退出标签交互态。

## 数据与兼容

- Schema v8 引入 `DiagramElement.labelPlacement`，保存可选的 `top | right | bottom | left`；Schema v10 在 `DiagramElement.labelVisible` 保存单图元显隐状态，当前 Schema v11 继续沿用，缺省表示显示。
- v1–v10 项目载入时升级为当前 v11；旧图元默认显示标签，v1–v7 项目仍会为缺少设备标识的既有图元生成稳定默认标识。
- 标签方位进入 JSON、IndexedDB、撤销/重做及图元复制；自动计算出的具体坐标不持久化。
- 单图元显隐设置与图元其他属性一样进入 JSON、IndexedDB、撤销/重做及复制，不改变设备标识内容。
- 重复设备标识暂不阻止保存，右侧属性面板给出提示，由用户决定是否修正。

## 验收要点

- 新建及旧项目图元默认显示设备标识且没有标签卡片；关闭某一图元开关后只隐藏该标签，其他图元和母线标签保持不变。
- 标签自动避让图元锚点出线区域，旋转图元后文字不旋转、侧向不改变。
- 未单选图元时点击标签区域不会直接选中标签；单选图元后可将标签拖到四侧并撤销/重做。
- 多选时标签不可拖动；标签不改变框选、吸附、图元变换和线路路由结果。
- JSON 往返、浏览器本地保存及复制后标签内容和人工侧向保持一致。
- 复制隐藏标签的图元后副本保持隐藏；撤销/重做、保存、打开及 JSON 往返后显隐状态不丢失。
