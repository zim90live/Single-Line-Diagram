# 第一阶段基础编辑验收清单

- 状态：待用户验收
- 日期：2026-08-13
- 适用版本：`0.1.0`

## 验收边界

本轮验收基础编辑、图元锚点定义和指定图元实例颜色，不验收线路连接、线路管理、监控模式、服务端存储或多人协作。当前素材库登记 21 个 SVG 文件并呈现为 20 个逻辑图元。

自动化负责数据、构建和可断言交互；布局、观感、标尺/网格视觉一致性及图元显示效果由用户目视验收。根据项目约定，本轮没有使用截图方式替用户做视觉结论。

## 启动前检查

- [ ] 执行 `npm install` 后依赖安装成功。
- [ ] 执行 `npm run dev`，使用桌面 Chrome/Edge 打开本地地址。
- [ ] 浏览器窗口宽度不低于 1180px。

## 功能验收

### 项目与层级

- [ ] 冷却、电力两套线路均显示独立的园区、楼宇、POD、设备层级。
- [ ] 点击任一子图纸可下钻；顶部线路标签、面包屑、画布标题与层级树保持一致。
- [ ] “返回”逐级回到父图纸，面包屑可直接返回任一祖先图纸。
- [ ] 新建项目时，存在未保存修改会提示确认。

### 图元插入与选择

- [ ] 图元可从素材区拖入画布，落点与鼠标位置一致并自动选中。
- [ ] 双击素材可插入画布中心。
- [ ] 图元按 SVG 原始宽高插入，未选中时画布只显示 SVG 内容，没有自动名称、背景色或卡片外壳。
- [ ] 素材区只显示一个名为 `Switch` 的图元，插入后默认呈现 Off；不单独显示 Switch On 或 Switch Off 素材项。
- [ ] 单击单选；按 `Shift`、`Ctrl` 或 `⌘` 可追加/移除选择。
- [ ] 在空白画布拖动可框选多个图元；右侧属性栏显示多选数量。
- [ ] 多选时每个图元都有独立选中轮廓，外层有一个整体包围框及缩放、旋转手柄。

### 图元变换

- [ ] 拖动图元可移动，位置对齐 8px 网格。
- [ ] 按下已放置图元或在不足 8px 的吸附范围内拖动时不显示十字带；产生实际网格位移后才显示，结束或取消拖动后立即消失。
- [ ] 多选拖动时每个图元都显示宽高对应的十字带；任意重叠区域与单独区域保持同一颜色和透明度。
- [ ] 选中图元后只能等比缩放，宽高始终是 8px 整数倍；CHWP 200×80 最小缩放到 40×16。
- [ ] 旋转控制柄以 90° 为步进旋转。
- [ ] 多选整体缩放保持每个图元的原始宽高比和相对位置；整体旋转围绕选区中心且以 90° 为步进。提交后每个图元的 X、Y、宽、高均为 8px 整数倍。
- [ ] 右侧属性栏修改 X、Y、缩放百分比和角度后，画布按相同约束更新。
- [ ] 修改名称和设备标识后，选择状态和属性数据保持一致。
- [ ] 选中 2WV、CV、Generator、Grid、MP、Switch、Transformer 时，右侧显示“图元颜色”；选择颜色后画布即时更新，“恢复默认”回到 `#777777`，其他图元不显示该字段。

### 画布与标尺

- [ ] 顶部与左侧标尺清晰可读，原点和刻度随画布平移、缩放同步变化；每个刻度直接对应当前显示的网格点。
- [ ] 画布使用单级点阵且不出现连续网格线；所有可见点的大小、颜色和透明度一致，没有主次点区别。
- [ ] 滚轮无需组合键即可按指针位置缩放画布，百分比显示正确。
- [ ] 滚轮缩小时，状态栏和画布当前可见间隔依次使用 8、16、24、32px 等 8px 倍数；屏幕点距不小于 8px，网格原点不会相对图元漂移。
- [ ] 按住鼠标中键拖动可平移画布，即使起点位于图元上也不会误触选择。
- [ ] 自适应点阵、图元轮廓和变换手柄在常用缩放级别下清晰，点阵不会压过 SVG 内容。

### 历史、剪贴板与删除

- [ ] 移动、缩放、旋转、属性修改、插入和删除可撤销/重做。
- [ ] `Ctrl` / `⌘` + `C`、`V` 可复制粘贴，粘贴结果有位置偏移并自动选中。
- [ ] `Ctrl` / `⌘` + `A` 可全选当前图纸图元。
- [ ] `Delete` / `Backspace` 和工具栏删除只删除当前选择。

### 图元锚点编辑器

- [ ] 素材卡片 hover 或键盘聚焦后，右上角出现编辑图标；点击不会拖动或插入图元。
- [ ] 编辑弹窗左侧显示全部图元并支持搜索、分类和单击切换；右侧画布是主要面积，使用 8px 点阵。
- [ ] 锚点只能添加或拖动到图元边缘的 8px 网格点，四个角和重复位置不可用。
- [ ] 顶部名称输入框、类型下拉以及撤销、重做、删除图标状态与所选锚点同步；界面不提供方向编辑。
- [ ] 电力默认类型为“电路”，冷却默认类型为“通用”；六种类型能够明确区分，不能只依赖颜色理解。
- [ ] 修改即时生效；弹窗没有取消或应用按钮，右上角关闭和 `Escape` 直接退出且不回滚修改。
- [ ] 保存、重新打开、JSON 导出导入后锚点保持一致；图元实例缩放和旋转时端点换算结果正确。

### 保存与交换

- [ ] 保存后状态变为“已保存”；刷新页面后通过“打开”可恢复项目。
- [ ] 图纸层级、所有图元的位置、尺寸、角度、名称和属性在重新打开后保持一致。
- [ ] 指定图元的自定义颜色在保存、打开和 JSON 导入导出后保持一致；旧 v1/v2 项目中的 Switch On/Off 自动迁移为统一 Switch。
- [ ] 导出生成单个 JSON；把该文件重新导入后得到等价项目。
- [ ] 导入损坏 JSON、错误版本或缺失素材引用时显示错误，当前项目不被替换。
- [ ] 删除本地项目只移除浏览器 IndexedDB 副本，不影响已导出的 JSON。

## 视觉验收（由用户执行）

- [ ] 画布是第一视觉焦点，左右侧栏和顶部控件不会压过编辑区。
- [ ] 中性深色工作面、低对比分隔、冷灰文字和克制的冷却/电力语义色符合极简、长时间运维操作预期。
- [ ] 左侧冷却/电力及各级图纸节点均为单行；长名称省略但不增高行。
- [ ] 在常用桌面尺寸和不超过 720px 的矮屏高度下，工具栏、素材区、属性区无明显遮挡或错位。
- [ ] 冷却与电力代表性图元显示完整，无裁切、模糊或标签覆盖。
- [ ] 禁用、悬停、选中、框选、缩放和旋转状态易于区分。
- [ ] 锚点编辑弹窗保持中性、克制、精密；顶部工具栏不过度拥挤，边缘候选点、已选锚点及六种类型易于辨认。
